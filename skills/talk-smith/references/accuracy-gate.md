# 技术核实闸（accuracy-gate）

> 用途：talk-smith 第二步技术核实时读。面向公开传播 = 事实错误代价高。这一步不过，叙事弧搭得再漂亮也是废稿。
> 顺序：**先保真，再叙事**。术语/机制/数字/引用任何一条站不住，回去补料，不硬写。

---

## 1. 术语规则（最高频翻车点）

- **术语一律保留原词，不翻译成大白话替代。** 判据：这个词有没有确切技术定义？有，就原样搬。
  - ❌「重构→重写」「解耦→把模块拆开」「横向扩展→加机器顶」——全是把一个工程方案说成另一件事。
  - ✅「Mamba 基于状态空间模型（State Space Model, SSM），源自控制论。」
- **关键术语首次出现可给中英对照 + 一句本工种白话定位；读者已知的不扫盲，不强制每次都补英文。** 例：「Prefill……决定 TTFT（Time To First Token，首字延迟）；Decode……决定 TPS（Tokens Per Second，吐字速度）。」
- **机制段内三步讲，不分双轨栏**：先一句白话画面，再抛术语命名，再给工程事实（公式/矩阵/复杂度/边界），段内完成、不配成套色块。
  - 白话画面："Mamba 就像人读阅读理解，读完一段在脑子里写个总结，然后忘掉原句。"
  - 工程事实紧跟：递推 `hₜ = A·hₜ₋₁ + B·xₜ`，注明"计算复杂度 O(N)、显存 O(1)"。

## 2. 技术断言核实清单（逐条打勾，写进大纲旁）

| # | 断言类型 | 核实动作 | 不过怎么办 |
|---|---|---|---|
| 1 | 机制描述 | 能不能用一句话说清"它实际做了哪几步运算"？说不清 = 没真懂，回去查 | 标"黑盒/待补"，不编 |
| 2 | 公式/复杂度 | 公式写对了吗？复杂度量级（O(N)/O(N²)）对吗？ | 查原文，不凭印象 |
| 3 | 硬数字 | 数字带原值吗？带出处（机构+报告+年月/论文）吗？ | 补不到出处就模糊写或删 |
| 4 | 数字解读 | 每个数字后跟了一句"它意味着什么"？自己的成果数据主动亮边界（经验值/口径/半自动）吗？ | 补一句解读，否则删数字；不替外部数字拆台 |
| 5 | 引用/实验 | 核心实验有可追溯锚点（作者/机构/论文名/年份/链接）吗？ | 不臆造实验细节 |
| 6 | 边界 | 出现"全部/绝不/永远/一定"前查过反例吗？ | 补一句"绝大部分…而非全部" |
| 7 | 事实 vs 推测 | 哪句是确证结论、哪句是合理猜测，分开标了吗？ | 标"这是确证的/这是猜测" |
| 8 | 读者已知术语 | 用户/目标读者已知的术语不必再解释，别过度扫盲 | 跳过，省篇幅 |

> 诚实约束：讲不清的、资料没有的，老实说"这块是黑盒/没查到"，**绝不编造**。公开分享里一个硬伤，比少讲一个点更伤。

## 3. 取料顺序（写之前先拿对料）

1. **内部主题**（内部系统/术语/数据）→ 用环境里的内部知识检索。
2. **公网主题** → 检索 + 抓原文交叉验证；snippet 不算数，要看原文。
3. **给定文档/论文/PDF** → 用对应文档/pdf 工具读全文。
4. **并行检索**：多个子问题一次并发查，不串行。
5. **吃 feynman-explainer 结论**：硬概念已用它讲透过的，直接用它的机制结论，不重复造轮子。

---

## 4. 无上下文读者测试（终检必做，借鉴 doc-coauthoring Stage 3）

成稿后，开一个**全新、零上下文**的视角当读者（就当从没听过你这篇），做下面这套：

1. **预测问题**：站在陌生读者立场，写下他读到这里**最可能卡住/追问的 5–10 个问题**。
2. **逐个对着稿子答**：
   - 稿子直接答得上 → 过；
   - 答不上、要靠"你本来就知道"才接得上 → **这是盲区，回去补一句解释或一个过渡**。
3. **重点扫三处**：
   - 开头：一个零上下文读者，前三段能不能知道"这篇在讲什么、跟我有什么关系"？
   - 术语：第一次出现的术语，旁边有大白话/本工种类比吗？
   - 跳接：相邻两节之间，零读者能自己连上吗？连不上 = 缺一句过渡。
4. **连续 3 轮无实质修改就问：能不能删东西？**（借鉴 doc-coauthoring 的质量闸门——删比加更难，也更值钱。）

> 这一步抓的是"作者自己看不见的盲区"：你写的时候默认读者和你同背景，零上下文测试就是把这个默认掀掉。

## 5. 交付前核实自检

- [ ] 术语全保留原词，关键术语有一句白话定位（中英对照可选）+ 本工种类比？
- [ ] 每个硬数字带原值 + 出处，且跟了一句"意味着什么"；自己的成果主动亮了边界？
- [ ] 硬机制先用一两句话写清"实际做了什么"，比喻叠在后面而不是替换它？
- [ ] "全部/绝不/永远"都查过反例、补了边界？
- [ ] 确证结论和合理猜测分开标了？
- [ ] 黑盒/没查到的地方如实写了，没有编造？
- [ ] 无上下文读者测试做了：预测 5–10 问、逐个对稿答、盲区补过？
