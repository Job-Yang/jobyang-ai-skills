# 成稿质检闸（qc-checklist）

> 用途：talk-smith 第五步质检时读。五维评分借鉴 stop-slop"五维打分 + 低于阈值重写"的思路，**中文技术分享场景自写适配版**——维度按 talk-smith 的产物目标重定，不照搬英文短语表。
> 评分方式：每一维 0–10 分（整数），五项相加满分 50。打分要给一句证据（引用稿子里的原句），不许凭感觉给分。

---

## 五维评分表

| 维 | 问自己 | 0–10 判分锚点 |
|---|---|---|
| **① 开头与开场** | 选了哪种开头（TL;DR 卡片五字段/先成果后过程/现场钩子）？有没有"本文将介绍/在当今时代/随着…发展"这类导语？ | 10=第一入口就抓住人；5=有开头但弱；≤4=寒暄开场或空导语 |
| **② 技术准确** | 术语保留原词+关键术语白话定位（中英对照可选）？机制段内三步（画面→命名→工程事实）？硬数字带出处？"全部/绝不"查过反例？ | 10=每条断言站得住；5=个别术语没定位/数字没出处；≤4=机制被比喻替换或数字无据 |
| **③ 叙事弧** | 推进链首尾咬合吗？最易想错的一节、自我拆台（亮半成品+留下了什么）在不在？抽掉中间一节后面还接得上吗？ | 10=删一节后面断；5=基本是链但有并列要点；≤4=平铺要点清单 |
| **④ 节奏与密度** | 长短句搭配？H2/H3 是短模块目录（不编号、不写成论点句）？对比/选型上三列表？幽默是否只在三处、按剂量？有没有删掉不丢信息的水段？ | 10=每段都在替主线说话；5=有少量水段或幽默超量；≤4=课件腔串联/形容词堆密度/硬俏皮 |
| **⑤ 可转述与收口** | 一句话主线+主线词能不能背走？结尾有没有 3 条平实启示？方法收成可数结构了吗？ | 10=读者合上能向人转述；5=有主线但收口空；≤4="以上就是我的分析"式空收 |

## 阈值（写死）

- **总分 < 38 / 50 → 整篇重写**，不是修修补补。
- **任一维 ≤ 4 → 该项必改**，哪怕总分过线。
- **② 技术准确维 ≤ 6 → 不许交付**（面向公开传播，准确是底线，不接受"先发表再改"）。
- 打分时把五维分数和证据句写进交付说明；写不出证据句 = 没打分，不许交。

## 机器能判净的硬约束（真跑脚本）

五维是人工判意图；下面这些机器一扫一个准，**必须真跑 `python3 scripts/talk_check.py <稿子.md> --state article|talk|slides`，命中数贴进交付说明**：

- 禁开头语："本文将介绍/在当今时代/随着…的发展/众所周知"出现在开头；
- 钩子缺失：前 3 段没有数字、引语「」、问句、或具体人名/画面标记；
- 字数区间：按 state 偏离目标区间（article 2000–5000 / talk 按分钟换算 / slides 页数）；
- 章节完整性：H2 数量低于该 state 下限；
- 结尾缺失：末尾没有启示/动作词（明天/下一步/可以试试）或加粗收口句；
- 新结构项只出 WARN（不强制）：TL;DR 五字段、系列交代块、"先看数据"成果节、设问计数；正式/事故场合出现卖萌符号给 WARN；幽默不做机器硬判；
- 未核实断言：正文残留 `TODO`/`待补`/`[?]`/`待核实`；
- 中文夹半角标点：中文字符之间夹半角 `,.;:`（代码/英文/数字千分位/URL 除外）。

> 半角标点这类字面毛病清到零；意图类（开头强弱、启示收得实不实、幽默分寸）只出建议、人来判，机器不自动改稿。

## 交付前三问（人工终审）

1. **零上下文读者测试做了吗？**（见 accuracy-gate §4）——预测 5–10 问，逐个对稿答，盲区补过。
2. **过 haohao-shuohua 重档了吗？**——定稿去 AI 味，它是唯一事实源；术语原词/数字/机制不动。
3. **去个人化了吗？**——稿子里没有照搬任何作者的成套 emoji 配色、栏目号、私人梗原句、口头禅、个人比喻库；鼓励按本人口吻造同类自嘲，但不抄句子；保留了动作，没复制人设。
4. **幽默剂量对吗？**——只在成果区拟人/节间转场/自我拆台三处，每 2000–3000 字一处、全文 8–10 处封顶；严肃事故复盘/对外正式发布/法律安全场合为零（判定线见 style-cn-tech §4）。

任一答不上，回去补。
