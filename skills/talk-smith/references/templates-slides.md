# 模板 · 演示幻灯片 slides（templates-slides）

> 用途：talk-smith 产物是技术分享 slides/演示分镜时读。
> 分工：**talk-smith 只产"叙事分镜"（每页讲什么论点、配什么证据）**；真要生成 `.pptx` 文件交本地 ppt 技能。本技能不自己排版式、不摆节点。
> 结构顺序查 `narrative-arc.md`，句子语气/幽默剂量查 `style-cn-tech.md`。

---

## 分镜骨架（一页一个论点）

| 页 | 论点（这一页只讲这一句） | 屏幕上放什么 | speaker notes（口播） |
|---|---|---|---|
| 封面 | 标题：口语钩子 + 正式术语 | 标题 + 一句话主线 | 开场第一句 |
| P1 · TL;DR 首页 | 五字段压成一页：干了啥/最大的坑/真正收获/这篇讲/最后引出 | 5 条短句，每条一个加粗词 | 逐条口播，先给结论 |
| P2 | 主线 + 主线词 | 一句主线句 + "记住这个词" | 埋主线词，预告后文回收 |
| P3–4 | 现象/案例 / 先看结果 | 一个具体画面/一张截图/一组硬数据 | 具体画面/硬数据；成果区一句拟人 |
| P5–7 | 机制 | 一张流程图（交 engineering-docs）+ 一个本工种类比 | 白话画面→命名术语→点复杂度 |
| P8 | 最易想错的一点 | "你以为 X，其实 Y"大字对比 | 把误区说透 |
| P9 | 选型对比（需要时） | **方式 / 行不行 / 原因**三列，✅/❌/⚠️ 标记 | 逐行讲一句原因 + 边界注 |
| P10 | 自我拆台/边界 | 亮明经验值/半自动/没走完 + "留下了什么"一条 | "把话说到边界上"；1 处自嘲 |
| P11 | 可搬走的硬货 | 三栏：动作 + 适用场景 + 代价 | 每块回去能试什么 |
| P12 | 收口 | 三点启示大字（可选金句/一个明天动作） | 启示收，留 Q&A 问题 |

# TL;DR
- 干了啥：……

- 最后引出：……

## slides 特有写法

- **每页一个论点句**，不是名词标题。屏幕上不超过 1 句论点 + 1 个支撑元素。
- **字少**：幻灯片是给听众看的锚点，不是演讲稿。细节全进 speaker notes。
- **图当证据**：架构图/流程图交 engineering-docs 出 SVG；一页一图，图旁一句"这张图在看什么"。
- **金句页和收口页可以大字满屏**，其余页克制；幽默不搬上屏幕卖萌，只留在 speaker notes 口播。

## 三态互转要点

### slides → article（分镜改成文章）
- 把每页论点句扩成一节：补机制、出处、反例、三列表。
- speaker notes 里的口播过渡/设问，化成文章小标题之间的承接。

### slides → talk（分镜改成讲稿）
- 每页扩成一个时间块的口播稿：补过渡设问、重复主线、数字的大白话解读。
- 按 templates-talk 的时间块重排。
