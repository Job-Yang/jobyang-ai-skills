# 待判断的题：怎么问作者

作者的时间最贵。流程绝不等作者：每道题都有保守默认，不回也照常跑。问作者只为两件事：裁判真判不了的地方，以及每周抽查裁判准不准。

---

## 问什么

| 类型 | 什么时候出 | 问法 | 超时默认 |
|---|---|---|---|
| 保真 | 裁判判「不确定」，拿不准这处算不算改了意思 | 这处改写有没有改掉原文的意思？ | 有 |
| 场合 | 裁判判「不确定」，拿不准这个语气合不合这个文体 | 放在「文体」里，这个说法有没有不合适？ | 有 |
| 新问题 | 裁判报了一种症状库里没有的 AI 味 | 改写这句读着还有 AI 味吗？ | 没有 |
| 抽查 | 每周一从裁判判「合格」的新题里随机抽 3 条 | 整段看，这版改写有没有改坏或者没改好？ | 跳过 |
| 体检 | 裁判体检时，作者当年判绿的改写被裁判判成改坏（编造除外），每份只问一次 | 这处算不算改坏了？（附作者当时的评语） | 跳过 |

每道题只给一句原文片段、一句改写片段，外加裁判拿不准的理由，作者不用读全文。抽查例外，给的是整段，但只抽 260 字以内的短稿。

## 怎么展示

日报最多列 3 条，保真排最前，然后是场合、体检、新问题、抽查；同类里先列影响召回的，再列只影响发布判断的，最后按时间先后。样子：

```
D12 · 保真 · 故障通报
  原文：业内普遍认为，连接池配置不当是此类问题的主要诱因
  改写：根源是连接池配置不当
  拿不准的地方：原文是「业内普遍认为」，改写说成了定论
  这处改写有没有改掉原文的意思？ 回复「D12 有」或「D12 没有」
```

作者回「D12 有」「D12 没有」「D12 跳过」都行，也认「是」「否」，可以带一句理由。一次回好几条也行。

## 回答怎么生效

- **作者亲口回答的**：
  - 进判例库，以后相似的情况裁判会读到作者原话。
  - 保真、场合、新问题答「有」，而且是现用版的改写，这条进问题池，跟别的召回一起攒病灶。新问题确认后按 `R·新` 攒，攒够了照样出候选。
  - 抽查答「有」算裁判漏判一次，答「没有」算判对一次。答过至少 5 条以后，漏判超过一成就暂停自动发布。
  - 体检答「有」，这份历史改写以后在体检里按改坏算；答「没有」，以后按确认过的绿算。
  - 回答可以改：同一道题再回一次，以最后一次为准，问题池和判例库会跟着换。
- **超时按默认处理的**：只是把这道题关掉，不进判例库，不进问题池。保守的效果在当天就已经生效了：门禁把候选版判「不确定」的题按改坏算，拿不准就不发布。
- **自动套判例的**：新题跟作者答过的某道题几乎一样（相似度 0.75 以上），直接照作者当时的回答处理，不再问；现用版的「有」照样进问题池。自动套用的不进判例库，免得一条判例自我复制。抽查和体检不自动套。

## 执行

作者的回复可能出现在任何会话里。见到就执行，执行完把命令输出原样回给作者：

```bash
python3 scripts/loop.py disputes answer D12 有 --note "作者的理由原话"
python3 scripts/loop.py disputes list          # 还没回的
python3 scripts/loop.py disputes list --all    # 全部，带状态
```

不许替作者回答，也不许把作者没回的题当成已回答。作者的理由原样写进 `--note`，不要改写、不要总结。
