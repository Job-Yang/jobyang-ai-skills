# 改前逐字扫 · 正则速查

这一页配套 SKILL.md「改前逐字扫（四条零容忍）」和「交付硬闸」。跳过感觉，直接用正则在字面上扫。

**用法定位（分两档）**：
- **半角标点这条进交付硬闸**：要写回飞书、对外发布的成稿，命令必须真跑、命中清零、结果贴进修改报告，不跑不交（细则见 SKILL.md「交付硬闸」）。
- **其余三条 + B2 是体检报告**：跑出来的命中数交人判，误报豁免在修改报告里说明，跑不过不阻断交付。

**每条靠什么兑现（机检 or 人读）**：

| 检查项 | 兑现方式 | 谁判 / 退出码 |
|---|---|---|
| 中文夹半角标点 | `quick_scan.py --checks half`，退出码即门禁 | 机器判死（零误报），**唯一默认卡退出码的真硬闸** |
| 破折号串 | `--checks dash` 报出现处与次数 | 提示项；机器粗报，人留 1-2 处真停顿 |
| B2「不是X是Y」变体 | `--checks b2` 报命中，全文数 ≤2 | 提示项；机器只报形式，**意图人判**（绝不自动改） |
| 元话语（值得深思…） | `--checks meta` | 提示项；命中建议删，但默认不卡退出码 |
| 章节机械编号/量词标题 | `--checks heading` 只扫 `#` 标题行 | 提示项；工具说明书/清单编号由人豁免 |
| 正文里的免责尾巴 | `--checks disclaim` | 提示项；原文本来就写着的「尚未核实」照留，**人判** |

**退出码口径写死**：默认 `--fail-on=half`，只有半角标点命中才退出 1；破折号/B2/元话语/序号标题/免责尾巴都是提示项，默认只报告、不卡交付。要把某条也变硬闸，显式 `--fail-on meta,dash,b2` 打开。这消除了"嘴上零容忍、实际不卡"的名实矛盾。

凡是写「零容忍 / 硬闸 / 强制」的，兑现方式都在上表里——不靠模型自觉，靠脚本真跑。

## 四条零容忍正则

### 1. 章节序号 + A1 量词标题(零容忍)

**扫**：两类拿数量当章节标签的标题——① 机械编号：「一、二、三、四」「第一章/第二节」「1. / 2. / 3.」这类给章节排顺序号的；② 量词标题：「其一/其二/其三」「第一 X/第二 X」「N 刀/N 步/N 条/N 板斧/N 维度」。数量不是判断，给章节按顺序编号是 AI 手感最稳的一处，人写字很少这么干。

```regex
^#{1,6}\s*([一二三四五六七八九十]+[、\.]|第[一二三四五六七八九十0-9]+[章节、]|[0-9]+[\.、）)]|其[一二三四五六七八九十]|第[一二三四五六七八九十0-9]+[步刀条个板斧维度方面]|[一二三四五六七八九十0-9]+[刀步条板斧维度][^\n]*)
```

**处置**：命中即改，把编号/「第 N 刀」删掉，让每个小标题自己是一句能立住的话。

### 2. B2「不是 X 是 Y」变体族(密度红线全文 ≤ 2)

**扫**：含「不是 X，而是 Y」「这不是 X」「A 不是病，B 才是病」「管的是 A 不管 B」「不在 A，而在 B」，以及翻案体「你以为 X 其实 Y」「看似 X 实则 Y」「表面上 X 实则 Y」「回头才发现」「真正 X 的是 Y」「A 不重要，重要的是 B」等结构。

```regex
(不是[^，。；\n]{1,30}[，,](而)?是[^，。\n]{1,30}|这不是[^，。\n]{1,30}|管的是[^，。\n]{1,20}不管|不在[^，。\n]{1,15}[，,]?而(在|是)|你以为[^，。\n]{1,30}[，,]?其实|(看似|表面上)[^，。\n]{1,30}[，,]?实则|回头才(发现|明白)|真正[^，。\n]{1,20}的是|不重要[，,]重要的是)
```

**处置**：全文命中 ≤ 2 处。超出即改，把 Y 单独立成陈述句，X 那半删或改让步。

### 3. 元话语(零容忍)

**扫**：抬姿态的空判断词。

```regex
(值得深思|值得关注|值得玩味|不禁让人|引人深思|发人深省|令人深思|不禁要问)
```

**处置**：命中即删，或改成具体判断。

### 4. 中文正文里的半角标点(零容忍)

**扫**：中文字符之间夹了半角逗号 `,`、句号 `.`、分号 `;`、冒号 `:`。这是 AI 最物理的一条，模型直吐时没做全半角转换，人手打中文极少这么混。

```regex
[一-鿿][,;:]|[一-鿿],[^0-9]|[一-鿿]\.[^0-9]
```

**处置**：命中即改，半角「, . ; :」换成全角「，。；：」。**例外(不动)**：代码块、命令行、英文原文、数字千分位(`1,000`)、文件名/URL、小数点里的半角标点都是对的。所以正则对句号/逗号特意排掉了后接数字的情况，减少 `3.14`、`1,000` 这类误报；剩下的命中一律念一遍再判。

## 建议项：正文里的免责尾巴(不算零容忍)

**扫**：正文后面跟的那句交代，说自己依据了什么、没核实什么，或者把正文已有的不确定再补一遍。判据和例子见 `symptom-dictionary.md` 结构级第 6 条。

```regex
(以上|上述)[^。！？\n]{0,15}(仅|只)(依据|根据|基于)|(以上|上述)[^。！？\n]{0,15}按(你|您)的|未(做|经过?)?(额外|进一步|实际)?的?(核验|核实|核查|查证)(?!的)|(无法|没法|没有|尚未|还没)(核验|核实|查证)(?!的)|还(得|要|需要)看[^。！？\n]{0,15}(什么时候|何时)
```

**处置**：自己加的就删；原文本来就写着的是原意，留着。真有要提醒作者的，单起一段「【给作者】」。「尚未验证」「还要看测试结果」「未经核实的消息」这类正常说法，正则特意不报。

## 一键命令（跨平台，先跑技能自带脚本）

四条零容忍一次跑完，给出文件 + 行号 + 命中片段。**首选技能自带脚本**（纯标准库，macOS / Linux / Windows 一份代码通跑，不再依赖 GNU grep 的 `-P`）：

```bash
# 进到技能目录后，把 你的稿.md 换成实际路径（可一次传多个文件）
python3 scripts/quick_scan.py 你的稿.md
```

输出按类别分组：半角标点（硬闸）/ 破折号串 / B2 变体 / 元话语 / 序号标题 / 免责尾巴，每条带 `行号 + 命中片段 + 原文一行`。**退出码**：半角标点零命中 = 0，有命中 = 1（写回持久面的成稿要追到 0 才算过闸）；文件读不了 = 2。常用开关：

```bash
python3 scripts/quick_scan.py 稿.md --checks half,meta     # 只跑指定几类
python3 scripts/quick_scan.py 稿.md --fail-on half,b2       # 哪些类别命中就退出1（默认只 half）
python3 scripts/quick_scan.py 稿.md --quiet                # 只出摘要，不打印命中原文
```

脚本已经替你做了人最容易忘的那层**误报屏蔽**：围栏代码块、行内码、URL、markdown 链接里的 url、HTML 注释（含本技能自己的宪法标记）一律不扫；英文词尾贴的半角逗号（如「调用API,完成」）故意不报——只认中文字符直接贴半角标点，宁可漏这一处，也不误杀中英混排。剩下的命中仍要念一遍判真假。

**不想用脚本时的备选**（环境里没 python 才用；macOS BSD grep 没有 `-P`，半角标点那条改用 perl 单行）：

```bash
# 章节序号 / B2 / 元话语这三类用 -nE 即可，macOS 能跑；半角标点必须用 perl（BSD grep 不认 \x{}）
F=你的稿.md
grep -nE '^#{1,6}\s*([一二三四五六七八九十]+[、.]|第[一二三四五六七八九十0-9]+[章节、]|[0-9]+[.、）)]|其[一二三四五六七八九十]|第[一二三四五六七八九十0-9]+[步刀条个板斧维度方面])' "$F" || echo "(clean)"
perl -CSD -ne 'print "$.: $_" if /[\x{4e00}-\x{9fff}][,;:]/ || /[\x{4e00}-\x{9fff]\.(?=[^0-9])/' "$F" || echo "(clean)"
```

**Windows**：上面 bash 备选在 Git Bash / WSL 里能跑；原生命令行没有 perl/grep 时，直接用 `python scripts\quick_scan.py 你的稿.md`（PowerShell 里斜杠换反斜杠），这也是跨平台最稳的一条。

## 判读原则(重要)

1. **命中数不是分数**。看每条位置，念一遍，判它是真病还是误报(引用、术语、评论他人观点)。
2. **误报豁免写进修改报告**。比如引原文出现「不是 X 而是 Y」，在修改报告里注明「第 N 段是引原文，豁免」。
3. **不做重试循环**。跑一次就好，人判完就交。别为了把命中数压到 0 反复改，那是造分数。
4. **本页覆盖零容忍四条和免责尾巴这一条建议项**，不是全部 AI 味清单。剩下的走症状库五层扫描 + 节奏检查。
5. **半角标点是唯一进硬闸的一条**：它零误报、能判死，所以写回飞书的成稿这条必须清零、留记录。B2/车轱辘/梗/免责尾巴判不了意图，只列建议、交作者拍板，绝不自动改。

## A1 常见误报豁免

A1 正则字面上抓「数字 + 量词」，但下面这几类**只是恰好长成这个样子，不是排比病**，豁免：

- **「一条」修饰非量词的普通名词**：「一条能贴屏幕上的收尾清单」「一条压顶的界」——「一条」+「清单/界」是**普通名量搭配**，不是「一刀/一步/一条」这类"用数量当标签"的段落序列。判据：看**上下文有没有配套的第二条、第三条**，没有就是普通计数，豁免。
- **术语/引用里的固定说法**：「三段式」「两轴」「五步流程」被引用讨论时(比如反例、批评的对象)，不是本文在用，豁免。
- **表格 / 列表标号**：纯粹给读者查阅的编号(「第 1 条」「第 2 条」)，不是段落标题，豁免。

判据统一为一条：**它是"用数量给内容贴标签的段落序列"，还是"恰好含数量的普通表达"?** 前者改，后者留。
