# 场景禁改表：受保护跨度(Protected Spans)

改中文的过程里，**有些跨度一个字都不能动**。改前先把它们圈出来，当成不透明的黑盒，连内部标点都别碰。

---

## 一、绝对禁改(全档共享)

### 1. 代码与命令

- ` `` ` 反引号包住的一切
- ``` ``` ``` 代码块内的一切
- 命令行：`git commit`、`kubectl apply`、`pip install --user` 等
- 变量名、函数名、类名、文件名、路径
- 配置片段、SQL、JSON、YAML

**理由**：改一个字就跑不起来。

### 2. 数字与单位

所有数字、比例、时间、日期、单位。
- ❌ 把「3 秒降到 800 毫秒」润色成「大幅降低」
- ❌ 把「92.65%」改成「超过 90%」

**理由**：数字是事实，润色会失真。

### 3. 引号内的原话 / 引用

- `「」` `""` `''` 引号内如果是别人说的话、书里的原句、引用的判断，一律不动
- 括号内的引用来源、出处

**理由**：引用改了就成了伪造。

### 4. 人名、公司名、产品名、专有名词

- 人名(中/英)、职称
- 公司/组织/团队名
- 产品/项目/服务名(iOS、Cursor、Copilot、GPT-3……)
- 技术名词(RLHF、LLM、AST、RAG……)

**理由**：改错等于事实错误。

### 5. 链接与引用标记

- `[text](url)`、`http(s)://...`
- `[[title]](url)` 内联引用
- 脚注、上标标注、图片引用

**理由**：损坏可跳转性和可溯源性。

---

## 二、场景性禁改(按场景启用)

### PRD / 技术方案 / API 文档

以下额外视为保护：
- **接口签名**、**参数名**、**返回结构**
- **错误码**、**状态码**
- **协议名**(HTTP、gRPC、WebSocket……)
- **性能指标数字**(QPS、P99、latency……)
- **需求编号**、**tag/label**
- 状态机中的**状态名**

### Postmortem / 事故复盘

- **时间戳**(精确到秒的绝不动)
- **告警名**、**指标名**、**面板名**
- **责任人**(如果有)、**变更 ID**
- **根因描述**中的**因果链**方向：「A 触发 B」不许改成「B 因 A」等
- 数据面的**恢复百分比**、**影响范围**

### 周报 / 双周报

- **项目名**、**里程碑名**、**deadline**
- **进度百分比**、**遗留问题数**
- **人名和分工归属**

### 学术 / 严肃技术文

- **公式**、**符号**、**变量定义**
- **定理名**、**引理编号**
- **参考文献**的作者、年份、期刊、DOI

### 法律 / 合规 / 合同

**该场景整体建议不用本技能**：法律语言的严谨性要求高于中文自然度，一改就可能改变权利义务。

---

## 三、模糊边界：谨慎判断

以下需要**先问、再动**：

### 1. 「AI 味」引号里的抽象词

标点级症状库说「引号里的抽象词加引号是壮胆」，但如果这个引号是作者本人在做术语标注 / 强调 / 反讽，**不许删**。

判断方法：
- 引号里是**通用抽象词**(「底层逻辑」「顶层设计」「范式」)→ 大概率壮胆，可删引号或替换
- 引号里是**上下文里定义过的概念或既有术语**(「技术债」「上下文窗口」)→ 是术语，保留引号，只做减法不做替换

### 2. 「不是 X，而是 Y」句式

如果原文用这个句式**明确在做纠错**，比如「这不是 bug，而是 feature 的边界条件」，那就保留原意，只把句式改顺：「这不是 bug，是 feature 边界」或「这看着像 bug，其实是 feature 边界」。

**别一刀切**把所有「不是 X 而是 Y」都砍成正面陈述，那会把「纠正」变成「确认」，方向反转。

### 3. 三连罗列

症状库说逢三凑数要砍。但如果**真的就是三样东西**(比如「HTTP、gRPC、WebSocket 都支持」)，保留。

判断：三样能不能各自换一个词而不影响原意？能 → 凑数；不能 → 真的三样，保留。

### 4. 破折号

标题里零容忍，正文可留 1-2 个。**遇到人物对话、心理转折、真的需要一个停顿**的地方，破折号是合法的。

判断：换成逗号或句号后，读起来是不是缺了那个「顿一下」的效果？缺 → 保留破折号；不缺 → 换掉。

---

## 四、操作流程

改前：

1. **扫一遍全文，标出所有受保护跨度**(代码、数字、引用、专有名词、链接)。心里或暂存区打个标。
2. **判断场景**(对话？周报？PRD？硬文？)，启用对应的场景禁改项。
3. **动刀时**跳过所有受保护跨度，像看到红灯一样绕开。
4. **改完第一遍对账本**时，把受保护跨度一条条对回去，一个字都不许动。

任何一处对不上，该处回退到原文。**保事实 > 去 AI 味**，顺序不许换。
