# 坏动词与坏比喻诊断图谱与修法

本页解决两个实操问题：遇到 AI 常写的怪动词、坏比喻、翻案腔和官腔拔高时**怎么一眼认出来并动手拆掉**，同时**把真实的判断、力度、范围和历史原话一分不少地留下来**。

## 总原则：先分场合，再拆壳保肉

- **场合前置分档**：本页拆壳清理适用于技术文、方案、复盘、分享、周报、产品分析与观点长文；感谢信、内部信、公关与品牌公告、培训定性、slogan 从轻少改，保正式官腔、敬语、祝愿与正当排比；产品介绍、落地页、招聘 JD、活动宣传、新人自我介绍与答复邮件、客服话术，先按主文件保住竞争力定位、能力范围、诚意气势或礼貌功能件，同时照常清理空心官腔、副词堆砌、被动腔与翻译腔。
- **事实与判断层（肉，必须守死）与修辞壳层（壳，放心动刀）**：普通请求「润色 / 去 AI 味 / 写自然些」在非特殊场合默认清理坏动词、混搭或空心比喻、B2 翻案腔与官腔抒情尾巴，不用等作者另写「平实」。
- **最小失败单位**：整个类比有助理解、只坏在一个动词上，就保留类比只修那个动词；意象本身混搭、空心或比本体更绕，直接拆掉意象改直述，把藏在里面的真判断拎出来。
- **不借「未定」甩锅给作者**：删纯造画面的装饰词不需要为每个意象词找业务含义；上下文方向明确的倒挂词直接按正确方向修好。只有原文确实缺少事实依据、或存在会改变事实的多种读法，且当前走完整修改报告（非随手短改或「只给正文」）时，才保留未定项并写 `【给作者】`。

## 一、AI 坏动词六病（对照表）

下表列出研发与工作中文里最高频的六类坏动词；动手前先顺便对照原文，保住力度、范围和完成状态。

| 病类 | 一眼判据 | 常见坏句 → 改好（保住实际信息） |
|---|---|---|
| **跨物类错配**（主宾硬嫁接） | 动作的物理规律跟对象完全搭不上，却也不是行业通用术语 | 「把摘要蒸馏到邮件里」（实为原样粘贴）→「把摘要原样贴进邮件」；「把延迟拍平」→「把延迟压下来」；「把重复序列装满后激活」（上下文指放宽条件）→ 按真实改动直述 |
| **猛词虚用**（暴力词充气势） | 用「引爆 / 击穿 / 重塑 / 倒逼 / 赋能 / 颠覆」替代普通的增减、解决、推动 | 「新策略引爆了留存」→「新策略大幅拉高了留存」；「击穿研发瓶颈」→「解开研发卡点」（**保住原文的评价幅度，不降级成「有变化」**） |
| **万能空壳动词** | 「进行 / 实现 / 完成 / 作出 / 开展 / 打造 + 名词」，真动作被塞进了名词 | 「对异常日志进行全面排查」→「把异常日志全查了一遍」；「实现了首屏耗时的显著降低」→「首屏耗时明显降了下来」（**锁住范围「全」、幅度「明显」、完成态「了」**） |
| **喻体内部动作串线** | 本想用某个画面打比方，后面接的动作属于另一个行当 | 「这艘帆船踩下了油门 / 换上了弹匣」→ 混搭失效，拆回直述；「目录像灯塔把说明照进用户手里」→ 映射有效，只修动作：「目录像灯塔，帮人找到说明」 |
| **作用动词乱串位** | 「决定 / 影响 / 支持 / 触发 / 证明 / 承载」强弱和因果不同，却被当近义词乱换 | 「历史记录决定调度策略」（原文写的是影响）→ 改回「影响」；「支持并发」与「提升并发」不能互换 |
| **英文直译借译动词** | 照搬英文动宾搭配，中文另有自然说法（**正牌术语除外**） | 「拥抱变化 / 消费一篇文章 / 导航复杂业务」→「接受变化 / 读完文章 / 理清复杂业务」（术语「消费消息」「暴露接口」保留） |

## 二、AI 坏比喻五病（对照表）

| 病类 | 一眼判据 | 怎么下刀（拆壳保肉） |
|---|---|---|
| **混搭串线** | 一句之内拼了航海、枪械、医疗等两套不相干的画面 | 如「帆船换上了弹匣」「上了膛的回旋镖」「给免疫系统踩油门」：先看上下文讲的是速度、风险还是反噬，直接拆成直述（「速度上来了，返工风险还在」「省下的实现时间，后面可能全搭在兼容性维护上」） |
| **空心装深刻** | 前后已经把事实说清，偏要再贴一句宏大画面充哲理 | 如「积压的理解债已经生锈」「像素的灵魂已经起航」：删掉空画面；若画面里裹着独有真判断（「生锈」指越积越难清），拎出来直述（「积压的改动越来越难理清」） |
| **倒挂 / 费解** | 喻体比本体还冷僻，或把上下限、因果方向画反 | 用「拉高天花板」比喻「抬高门槛」、用「热力学熵增通道」解释清缓存：一律删比喻，直述正确方向 |
| **以喻代机制 / 代证** | 用比喻顶掉精确工程机制，或用「这就好比……所以……」充当论据 | 「attention 就像大家在嘈杂屋子里找朋友说话」**只叠在后面、不替代**「Q-K 相关度加权」；机制写前面，类比只能叠在后面助理解；缺真实机制证据且走完整修改报告时另写 `【给作者】` 提示补齐（短改或「只给正文」直接保原不追尾巴） |
| **陈腐模板（预制菜）** | 双刃剑、冰山一角、压舱石、护城河、照妖镜、底座、抓手、催化剂、温床 | 换回原文依据的具体利弊、比例或作用（如「一方面省时，另一方面容易漏测」）；**原文没有的数字、比例或后果一个字都不许自己编** |

## 三、四类正当表达（绝不误杀）

1. **有助理解的清晰类比**：科普或面向跨岗位同事的说明里，能瞬间看懂的类比必须留。例如用「路口交通警察指挥车流」讲负载均衡、用「一群人开会达成共识」讲分布式一致性、用「纸条放进笔记本 / 交到服务器」区分本机保存与云端同步。类比里只有小重复时（如「路口」连说两遍），只去重复不拆类比。
2. **已有引申义与行业术语**：`打破吞吐量纪录`、`价格降温`、`冷启动`、`重构`、`解耦`、`消费消息`、`暴露接口` 都已有通行词义或技术定义，绝不因为「记录不会真碎」「价格没有体温」判错。
3. **被报道言说、引文与批评对象**：报道「谁说过 / 认为 / 命名 / 写下什么」（哪怕没有引号），宾语属于历史内容。例如「旧访谈认为停电源于月亮断线」或明确引用的「回旋镖已经上膛」，外围表达可以顺，被报道和被批评的原话原词一字不动。
4. **规范与异常并存**：原文写「规程要求每日浇水，记录却写连续三日未浇」，规范不能覆盖已发生的异常。本体事实与记录真有冲突时保留原文，在 `【给作者】` 里指出冲突，不擅自择真改正。

## 四、拆壳保肉四个高频防翻车口诀

每次动手拆 AI 味句式，容易在「壳拆了、肉也伤了」上翻车。照下面四条锁死边界：

- **拆 B2 强对比与排除项，立住主判断，别降成并列、别丢独立论点与参照、别改超集**：`本质上不是 X，而是 Y`、`并不是 X，而是 Y`、`不在于 X，而在于 Y`、`X，而不是 Y`、`看似 X，实则 Y`、`你以为 X，其实 Y`、`实质是在……`、`手里调的是 X，赌的却是 Y`、`X 不重要，重要的是 Y` 需按语义拆掉翻案壳，让 Y 立为主判断并保住被排除对比，**同时完整留住原文每一条独立判断与紧随其后的实质结论句（不因合并句式吞掉独立命题）**，不降格成平列「不只是 X，也会 Y」；**唯独前后语境确属事实排错才写「与 X 无关」，能力权重对比或后文紧跟 X 的指标改善时保留主次比重（如「局部 X 解决不了根因，核心在于 Y」），绝不写「与 X 无关」或「超出了 X」**。
  - 坏例 1（权重对比）：「引入该层看着只省了一步计算，其实需要重排整条数据流；它的意义远超局部提速，关键在于重划权责边界。想透这一点，才能定准后续演进。」→ 好改：「引入该层看着只省一步计算，真正动起来却要重排整条数据流；比起局部提速，更关键的是重划权责边界。想透这一点，才能定准后续演进方向。」（保住数字「一步」、实际代价与必要条件，三条独立判断齐全且主次权重不降格。）
  - 坏例 2（事实排错）：「根因并不是流量突增，而是配置变更工具全量清空缓存」→ 好改：「故障根因是配置变更工具全量清空了缓存，与流量突增无关。」（留住排除项，不能整句删掉「流量突增」。）
  - 坏例 3（趋势反差）：「研发自测覆盖率看似稳步走高，实则仍有不少模块在发版前才突击补单测」→ 好改：「账面上的研发自测覆盖率在稳步走高，但仍有不少模块在发版前才突击补单测。」（保住「稳步」等真实趋势，不用「表面上看……实际……」。）
  - 坏例 4（主次对比）：「框架不重要，重要的是对问题的抽象能力」→ 好改：「选框架本身决定不了成败，真正决定结果的是抽象问题的能力。」（保留「选框架决定不了」的对照力度，不写成「不重要」也不改成无关。）
  - 坏例 5（因果动作）：「按生命周期分层，而不是盲目压缩」→ 好改：「按生命周期给上下文分层，不做盲目压缩。」
- **拆名词化与坏动词，锁死身份、归属、力度与境界线**：
  - 还原名词化短语时保持原主体身份（不擅自扩泛或偷换技术名词）、不凭空添原文没有的程度度量词（如擅加「牢固地」「薄弱处」「彻底」）。
  - 拆坏动词按当前语境直译实际动作性质：保留原文动作方向与评价幅度（如「深入」不暗降也不拔高成「彻底」，泛指系统底层不私自窄化成另一层组件），上下文方向明确但词义倒挂的病句直修，不借 `【给作者】` 甩锅；拆完回读动宾搭配与单复数指代是否通顺一致。
- **删套话与官腔拔高，不删真实计划承诺，也不脑补具体做法**：
  - 纯官腔抒情或空喊表态结尾（「这一课让我受益终身」「稳定性建设永远在路上」「任重道远」「再上新台阶」「标志着一次深刻变革」）在复盘、分享、技术文里直接删去，切忌换成另一句空壳（如「还要长期推进」「还要持续投入」「收获很大」「提供有力支持」）。
  - 只有当原文明确写出后续具体动作或真实机制承诺（如「后续会完善相关机制」「下周补充边界压测」）时，才剥掉表态腔后保留原计划，**绝不替作者编造原文没提的具体做法（如私自补「重点补监控」「加告警」）**。
  - 删「当然 / 另一方面 / 总的来说 / 废话不多说」等过渡套话时，用自然连词接住让步与转折，保住范围限定（「比较常见 / 多数 / 通常」）、比较幅度与作者态度。
- **修错别字与语序，只动坏掉的形式**：保留原文频率词（「都会 / 可能 / 经常 / 全部」）、观察主体（「谁推荐」不能变成「常看到推荐」）和时间范围。

**保真五项速查**（动完比喻、对比或转述后过一遍，全落在改后新句里才算过关）：
1. 评价或类别与比较力度；
2. 关系作用与因果方向；
3. 被报道宾语、引文与归属；
4. 范围、数量与频率模态；
5. 施事、受事、目的与完成状态。
