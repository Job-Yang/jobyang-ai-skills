# 动词与比喻的逐句核对

本页展开主文件的修改权限、用词和比喻判据。先理解任务范围的骨架与段意，再定位确有问题的表达；逐句核对不等于逐句重写，随手回复仍只在心里轻量核对。

## 先判能动什么，再找修法

按主文件的内容归属区分本稿表达、被报道的言说或记录、实际事实与判断、规范或期望。当前稿用于解释明确本体的临时修辞可以等义修；被报道内容、已发生行为及其依据、作者判断和立场须保住。

**谁曾说、认为、命名、报告或写下什么，宾语就是历史内容。** 没有引号也受保护；可顺外围表达，不能换成当时理应正确的内容。错词被引用作批评不算本稿新造词；真正术语、专名和引文保原词。

规范和定义说明“应如何”或“词是什么意思”，不能证明异常没有发生。原文说发生了异常、作了错误判断或留下错误记录，不能据常规定义改成正常行为；本体事实与记录冲突也不能自动择真。保原并具体提醒作者，清洗层不取得事实校正权。

把有权改的跨度放回完整句段，记清涉改信息及限定：施事、动作、对象、作用类型、说话归属、判断力度、条件与否定作用域、时间与完成状态、类别、来源去向、目的。目的包括要做什么和为什么；不能只留操作就删掉愿望或理由。结构编号承载真实层级、顺序、阶段或交叉引用时也受保护。

## 确定的问题要修，取舍依据是实际含义

“润色、写自然些”已经授权纠正表达。动词与对象错配、临时意象的动作混用、明确映射反转，都需要处理；是否另外说了“平实”，不改变纠错责任。已有引申义和真正术语按实际含义判断，不按字面物理动作判错。

先从完整句段辨明作者实际说了什么，再决定：

- **只错在动作**：映射本身帮助理解时，保留映射，只修不配的动作。比如“目录像灯塔引导查找”成立，坏的是“把说明照进用户手里”，改成“引导用户找到说明”即可；不能因一个坏动词删掉整段有效类比。
- **整个意象无助理解**：相邻句已交代同一事实、功能或判断，意象只是重复造画面时，可以删去；映射混用、前后指向相反时，也可整体换成直述。处理后读完整句，避免仅换词造成悬空宾语、重复谓词或另一种别扭表达。
- **比喻有效且适合任务**：保留它帮助理解的部分。操作说明、科普、个人随笔都可能需要类比，不单按文体删比喻。
- **实际信息确实未定**：不能猜动作、主体、范围、程度或历史事实。保留这个未定项并具体提醒，其他确定的问题仍正常修。

区分“实际含义未定”和“装饰词无法逐字解释”：上下文已说清本体，剩下只是给喻体造画面的词，不要求作者为每个词解释一层含义。也不能把所有形容词都当装饰；作者对实际对象作出的轻重、难易、类别和程度判断仍须保留。判断删除范围时先问：删掉的是整段映射，还是只删一个不配的动作？前者需要证明意象无助理解，后者只需修动作。

## 改写前核对五项实际含义

对涉及比喻、映射或转述的待改跨度，放回完整句段，核对以下实际含义及其条件、时间和完成状态。只为造画面的喻体细节不自动成为事实：

1. **评价或类别判断**：作者给出的性质、类别、力度、程度与比较参照。
2. **关系作用**：谁对谁起什么作用，以及因果、延续、说明、替代等关系。
3. **被报道宾语**：谁在何时说过、认为、命名或写下什么；宾语按历史内容保原。
4. **范围数量**：全量、部分、逐项、次数、覆盖对象及作用域。
5. **施事受事**：动作主体、承受者、来源去向和映射方向。

有实际含义的项目回到完整新句找等义落点；没有的项目记“无”。不要凭一个装饰词推测作者另有未说的业务含义。实际信息丢失就调整改法，确实缺少判断依据才保留未定部分并提醒。

**保住原意和修好表达要同时完成。** 删掉怪比喻但丢了事实不合格；保留全部原词却留下明确病句也不合格。实际含义均保住、新句自然准确，才算修好；作者提醒不能代替有条件完成的修正。

## 名词化改写先锁身份和程度

“对复杂度的掌控”是能力判断，改成“能掌控多大的复杂度”会新增可量化程度；“一个工程师”改成“一个人”会扩大职业范围。名词化可以拆顺，但原限定身份、对象、范围和程度要保住。需要补“多大／多少／更强”时，先确认原文有对应依据；没有就保留原判断，不替作者加量级。

## 拆“看似／你以为”先锁谓词

“看似 X，实则 Y”“你以为 X，其实 Y”常被当成翻案腔删除，但 X、Y 的原谓词是作者判断的一部分。改写时不能给 X 补“工作本身”“表面现象”等新宾语，也不能把“你以为”换成“你会发现”改变对话关系。先把 X、Y 和主语写清，再决定用“表面上……实际上……”直述；补不出等义谓词就保留原句并提醒。

## 过渡词可以删，关系和力度不能丢

删“当然／另一方面／虽然……但……／总的来说”之前，先判它是不是只做过渡。“这正是……所在”不是普通判断句，改成“这也是……”会新增并列关系、削弱强调；应保留“正是”或改成“这就是……的基石”。口播垫话也一样：删“那么／废话不多说”可以，但“我们要聊”的说话者和“非常有意思”的评价程度要留住。“比较常见／相对／多数／通常／部分”是范围限定，不能随套话一起删；删掉会把局部观察扩大成普遍判断。“低很多／高很多／明显／大幅／略高／基本持平”是比较幅度，不能降成“低于／高于”；数字、方向和幅度要一起保留。评价词“很棒／很好／非常清晰”不因删客套而降级；只删捧场和填充词，保留对对象的评价。若它承担让步、转折、主次或总结，删词后要用结构或简洁连接词接住。不能把“虽然定位慢，但止损比较及时”改成“定位慢，止损还算及时”这种平列句，也不能把“深刻地认识到”降成“更清楚地看到”。程度评价、让步方向和总结力度都属于作者判断，不是装饰。

## 强对比不能拆成并列

“不是 X 而是 Y”和“不在于 X 而在于 Y”表达的是排除与主次，不是 X、Y 两项都有价值。改写时让 Y 继续做主判断，X 降为表面或附属；“不只是 X，更是 Y”可以保留层级，“不只是 X，也会 Y”会把强对比削弱成附加项，属于判断力度漂移。原文的否定对象、比较参照和“本质上／真正”等力度词要一起核。

## 语法修复也有最小边界

错别字、重复字、并列标点和明显语序问题可以修，但只修坏掉的形式。原文的“都会／可能／经常／全部”等频率与模态、“谁推荐／谁看到”的观察主体、时间范围和对象归属都要保留。把“都会推荐”改成“常会看到推荐”会同时降低频率、换掉主体，属于改义；应只修语序，例如保留“视频都会推荐”的关系。

无法在保留主语和频率的前提下修顺时，保留原句并具体询问，不替作者补“需求”“原因”“结果”等原文没有明说的内容。历史段落中的口语和行业词按作者原声处理，不因不够书面而整体重写。

## 按用法取依据，意见成立后仍要验修法

同一个词在不同用法里不能按同一套物理规则判错：

| 用法 | 核对依据 | 能据此修改的范围 |
|---|---|---|
| 字面动作 | 原材料所述操作、主体、对象及权限 | 措辞误述原文已明确的动作时等义修；已发生操作不能改成规范操作 |
| 已有引申义 | 通行词义与本句关系 | 合义且得体就留；抽象主语做不出物理动作不构成反证 |
| 真正术语 | 专业定义与原材料 | 保留原词；词形陌生不能证明它是伪术语，也不以定义抹掉历史错误 |
| 临时比喻 | 喻体内部动作、文中明确建立的本体映射 | 只修有据的错词、动作混用或映射错置；不改本体事实 |

“听着怪”只触发核对。问题依据不足，先查上下文；仍不足以确定实际含义才保留并列具体疑问。一个坏词不使同句其他声明作废。“决定、支持、影响、执行、提出”是不同作用，不能为顺口互换。

以下仅为不同领域的假设示例，用来说明边界，不是固定换词答案：

| 片段 | 判断与处理 |
|---|---|
| 旺季价格降温 | 已有引申义，不能以价格没有体温判错；本句合义就保留 |
| 旧访谈认为停电源于月亮断线 | 正在报道当年的认知内容；错词不能换成正确原因，可改善外围措辞并指出具体疑问 |
| 规程要求每日浇水，记录却写连续三日未浇 | 规范与记录可以同时成立；不能据规程把记录改成每日已浇水 |
| 检索目录像路标，帮助读者找到馆藏 | 映射只说引导查找；不能从路标联想出系统必有道路或读者已经迷路 |
| 本稿以传统沙漏的漏沙对应倒计时，却说它靠上弦计时 | 喻体内部动作混用，可局部修表达；不能反推任务实际采用了哪种计时机制 |

## 比喻成立与本文需要，分开处理

先从原文和上下文辨明本体，再核喻体内部动作、关键对应和方向。门槛提高与上限提高对应不同关系，不能混用。喻体联想不是本体前提，不能先补一种物理性质、初始状态或限制，再拿它反证原句。

成立后才问是否更省理解成本：喻体是否熟悉、直述是否更清楚、是否符合读者和上游文体。同行文或用户要求平实的稿子优先直述；科普中的有效类比保留。连续换意象要核同一关系是否仍清楚，不以数量本身判错，也不为配额删到零。比喻不能证明因果，缺机制证据就具体提醒作者。

删换意象前，把实际信息与修辞画面分开。独有的目的、愿望、作用、评价或范围要等义表达；删实际命题时需确认它在稿中已完整承接，同主题不够。上下文已明确实际意思、且意象没有独立命题时，可去掉修辞，无需证明喻体每个词都在别处重复。不要为了凑承接编新事实。

形容词与限定词先核所指对象。实际功能的难易、覆盖是否全量、完成还是计划、来源与去向，均属需保留的信息；只描画喻体的外观和动作、不承担独立判断的词，可随无用意象删掉。不能把喻体外观挪成实际产品的性质。判断这一区别要用完整上下文，不能只靠词表，也不能因为可能有含义就一律保词。

## 改完核实际原句与新句

沿用 `workflow.md` 的同一账本，核受影响整句段及删句的上下文。原文→新稿找涉改实际信息的等义落点，新稿→原文逐项找出处；删除实际命题引用完整承接，删除装饰说明上下文中已明确的本体含义。保留相同主语或“已”字，不能证明行为宾语、依据和历史内容没变。

第二遍回读另以查错配、映射与新歧义为目标，不拿原改法的辩护作证据；同一意象或动作有问题时回查同篇其他位置，也查自己新写的句子。后续又改了字，受影响句段重新对账。

意见是否成立与改稿是否保真分开记。不等义先退更小改法；仍不能解决就保原并具体提醒，不声称已修。没有实质问题可登记“未发现需改项”，不硬找问题。

写回持久面的成稿，只展开实际涉改信息：原句及问题跨度、相应用法与依据、实际新句或删除承接、五项落点与逐项等义结果，并分别写明症状是否消失、是否安全修好。不能以“全部对齐”或整类勾选代替落点，不为未改好句建巨表。`quick_scan.py` 只定位形式，不能提供语义结论。
