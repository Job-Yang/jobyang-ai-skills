# 高定视觉工艺包（Craft Packs）与审美编译

本页提供 **9 套带高清视觉锚点、物理光影配方、非对称构图与物理动效的高定工艺包**，把“更高级、像真实大厂/精品独立应用、别呆板”直接编译为可执行起点。生成任何界面前，先按场景命中一套底座，先看对应样张图 `assets/craft-packs/<id>.png` 与样板源码 `assets/craft-packs/<id>.html`，再结合真实内容创作。

> **不止这 9 套：自由基因混搭**
> 这 9 套是高质量起跳锚点，**绝不是固定模板**。想做任意组合、跨界混搭（Remix），或沿 5 条正交轴＋三旋钮（`VARIANCE / MOTION / DENSITY`）从零合成全新流派，直接配合 `references/craft-genome.md` 使用。

## 九套高定工艺包核心配方

### 1. `liquid-glass`（液态磨砂玻璃 · Apple 空间通透风）
- **表面与光影物理**：底层铺海洋天青 `#0284C7` ＋ 海雾青 `#0D9488` ＋ 晨光暖金 `#F59E0B` 的柔和光氛（禁紫蓝渐变）；**仅悬浮导航岛、左侧快捷轨、底部播放器 Dock 采用液态玻璃**（`backdrop-filter: blur(22px) saturate(185%)`、`135deg` Fresnel 镜面亮边、顶缘 `0.85` 白高光、指针跟随微光）。**下方正文与列表严禁玻璃叠玻璃**，统一采用清晰实底与同心圆角（`26px` 外 / `12px` 内边距 → `14px` 内图框）。
- **核心色板**：海洋天青 `#0284C7` 作主交互点染，琥珀金 `#D97706` 标重点标签；支持一键「晴空通透 / 暮色晶透」双态。
- **空间构图签名**：顶部悬浮胶囊导航岛（含 3 项 `--spring-snappy` 滑动分段器）＋ 左侧玻璃图标轨 ＋ 中央高可读图文主舞台 ＋ 底部双胶囊分离播放器与速记按钮。
- **代表交互与动效**：Blur-Replace 切屏过渡、动态音阶动画、从右下按钮原位生长的 `transform-origin: bottom right` 速记浮层。

### 2. `nordic-frost`（极光雾面双态工作台）
- **表面与光影物理**：深海岩蓝极光底光 `#0D1620`（深空雾暗，可一键切 `#E8EFF4` 冰川浅雾）托起**彼此物理分离的圆角 `20px` 雾面面板**（`backdrop-filter: blur(18px)` ＋ `rgba(255,255,255,0.08)` 顶光边）；内部待决队列用发丝横线分段，杜绝多层白框套白框。
- **核心色板**：海湾青蓝 `#38BDF8` / `#0284C7` 作核心操作与活跃节点线，翡翠绿 `#10B981` 表通过，琥珀黄 `#F59E0B` 表人工判断门禁。
- **空间构图签名**：左侧独立圆角雾面侧栏 ＋ 顶部双态切换器与 AI 助理胶囊 ＋ 上半决策待办快速拍板队列 ＋ 下半 SVG 连线节点推进图与焦点检视条。
- **代表交互与动效**：Sonner 式右下角 3 层景深堆叠撤销浮条（支持一键退回）、点击节点联动高亮上游因果弧、右侧雾面 AI 助理抽屉滑入。

### 3. `tactile-hardware`（精密触感工业 · 仪器实体风）
- **表面与光影物理**：工程灰白哑光阳极铝机身 `#EEECE6 → #E3E0D7` 配精密加工分模线与实体喇叭微孔 SVG；微凹陷深碳黑 OLED 窗 `#121519`；带有 `0 4px 0` 立体侧裙与按下 `translateY(2px)` 真实塌陷手感的 3D 机械键帽。
- **核心色板**：工程暖灰机身配国际信号橙 `#EA4A1F` 主执行拨键，配合翡翠绿/琥珀/信号橙真实物理 LED 指示灯。
- **空间构图签名**：顶部型号铭牌与 LED 状态条 → 上半 `62%` 深碳 OLED 大数字计时与示波窗 ＋ `38%` 机械模式键帽矩阵 → 下半三路精密水平推子与信号橙大拨键。
- **代表交互与动效**：3D 物理键帽档位切换、三路声场推子实时改变 OLED 双重示波曲线幅度、信号橙拨键开启真实秒表与活体声波呼吸。

### 4. `kinetic-bento`（灵动便当展厅）
- **表面与光影物理**：暖骨白画布 `#F3F2ED` 托起强材质反差拼贴——深石墨指针跟随微光英雄台 `#14171D`、深森绿 `#0F4C3A`、暖陶土 `#C85A32` 与纯白数据卡同台竞艳；严格遵守 `R24 − P12 = R12` 同心圆角。
- **核心色板**：深石墨、深森绿与陶土红橙建立建筑级张力，禁用廉价紫蓝渐变。
- **空间构图签名**：12 列非对称便当矩阵——左 `7×2` 超大主导展演舞台（占首屏 `>55%` 视觉权重）配右侧数字反差 KPI、物理弹簧开关、几何徽章与底层曲线跑道对比区。
- **代表交互与动效**：Blur-Replace 切换核心能力、深森绿 `--spring-bouncy`（11.8% 弹性回弹）开关、可重播「物理弹簧 vs 传统 ease-in」跑道动画、`scale(0.94)` 聚焦模态框。

### 5. `obsidian-precision`（精密暗色仪器）
- **表面与光影物理**：深碳黑画布 `#0C0D10` 配高半档操作主面 `#14161C` 与内凹日志槽 `#090A0D`；卡片顶部加 `inset 0 1px 0 rgba(255, 255, 255, 0.08)` 模拟精密硬件边缘；顶部铺 `6%–9%` 极淡主色径向光晕。
- **核心色板**：翡翠信号绿 `#10B981` 主动作，琥珀黄 `#F59E0B` 表等待与人工门禁，天青 `#38BDF8` 表辅助遥测。
- **空间构图签名**：左侧 58px 窄图标轨 ＋ 中央主执行舞台（脉冲状态灯＋错峰时间线＋底部审批动作条）＋ 右侧 336px 并发队列与预算条。
- **代表交互与动效**：CSS Grid `0fr -> 1fr` 零回流日志展开、`⌘K` 毛玻璃命令面板、`scale(0.975)` 按压回弹。

### 6. `porcelain-craft`（温润瓷感节奏）
- **表面与光影物理**：浅矿石暖灰外底 `#F6F4EF` 托起纯白瓷面主画纸 `#FFFFFF`，配柔和两层暖影 `0 1px 2px rgba(28,25,23,0.04), 0 18px 42px -18px rgba(28,25,23,0.11)` 与极淡 `rgba(28,25,23,0.09)` 边线。

### 7. `editorial-ink`（纸墨编辑专栏）
- **表面与光影物理**：收藏级暖纸 `#FBF9F5` 配米灰 `#F3EFE6` 引言底面，几乎不用投影，靠 `1px` 细分割线与 `1.5px` 顶线确立杂志栏序（支持切换羊皮纸色调）。

## 图标与排版强反差铁律

1. **禁止使用 Emoji 当产品图标**：按钮、导航、分类项和卡片角标一律使用成套内联 `1.5px–1.8px` 线性 SVG，不放 `🚀/📊/🔥` 等表情符号；描边粗细跟随相邻文字字重。
2. **主标题或关键数字要敢放大**：主视图核心标题建议 `24px–36px`（字重 `700`），核心指标数值可用 `32px–56px` 并开 `font-variant-numeric: tabular-nums`，与 `12px–14px` 辅助元信息形成清晰对比；中文绝不加负字距。
3. **破除“均分卡片墙”**：先挑唯一主视觉对象占据 `55%–70%` 面积，再安排辅助队列、边注或次要卡片。

## 出图前六点视觉审视清单（基于 Playwright 实际截图）

使用 `node scripts/capture_preview.mjs` 截取桌面（`1440×900`）、手机（`390×844`）和关键点击状态截图后，务必亲眼打开图片核对以下 6 条：

1. **首屏一眼分出主次了吗？** 最核心的数据走势、执行流、OLED 视窗或主舞台是否第一时间抓眼，还是淹没在一堆平均大小的格子里？
2. **材质层级与同心圆角干净吗？** 是否误把玻璃叠在玻璃上导致发灰？外圆角减内边距是否严格等于内元素圆角？背景与工作区明暗差是否足够爽脆？
3. **字号和数字列对齐到位了吗？** 标题、正文、说明文字、数据金额之间的大小、字重与颜色反差够不够清晰？中文有没有发生难看的单字孤行？
4. **图表与图标干净吗？** 折线/条形图有没有刻度标签、图内文字有没有被边界裁掉？所有小图标是否都使用风格一致的细线 SVG？
5. **10% 慢放动效与高频反馈顺手吗？** 切页签、点开关、开抽屉时动画起手是否干脆不发黏、有无文字抖动或 `scale(0)` 突兀炸出、可撤销路径是否即时？
6. **去掉导航能认出产品气质吗？** 把顶部栏遮住，仅看主画面材质、字体节奏、结构组织与动效质感，是否体现明确的流派或成功混搭？
