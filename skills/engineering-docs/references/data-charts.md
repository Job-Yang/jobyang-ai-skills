# 技术文档中的数据图表

性能、容量、稳定性和成本方案中的数字需要独立处理。结构图表达关系，统计图表达数据。先确认数据与问题，再把字段映射到轴、颜色和标注；比例与位置交给标准绘图库计算。

## 按问题选图

| 问题 | 首选 | 必须保留 | 常见误导 |
| --- | --- | --- | --- |
| 指标如何随时间变化 | 折线 / 小多图 | 时间粒度、时区、聚合方式、缺测 | 把缺测当零；平滑掩盖尖峰 |
| 不同方案谁更高、差多少 | 条形 / 点图 / 哑铃图 | 同单位、可比负载、共同基线 | 截断条形轴；比较不同样本口径 |
| 请求大多落在哪、是否长尾 | 直方图 | 样本量、bin 边界、计数或密度 | 删除慢请求；不等宽 bin 用高度比频数 |
| 多少比例低于一个阈值 | ECDF | 全部样本、阈值、阶梯定义 | 把累计概率当概率密度 |
| 多组分布是否不同 | 箱线 + 原始点 | 中位数、四分位、须线定义、样本量 | 把须线当置信区间或固定 min/max |
| 两个指标如何共同变化 | 散点 | 样本单位、第三变量、异常点 | 把相关写成因果；无依据连接点 |
| 哪些时间/维度形成热点 | 热力图 | 两轴含义、色标、数值范围、缺测 | 每行独立归一化却共同解释颜色 |
| 总量由哪些部分构成 | 堆叠条形 / 100% 堆叠 | 分母、类别、总量、单位 | 比例改善掩盖绝对量恶化 |
| 总变化由哪些增减项贡献 | 瀑布图 | 初值、带符号增量、终值、闭合关系 | 重复算贡献；把无法相加的数相加 |
| 一个总体如何分成少数类别 | 饼 / 环形 | 互斥分类、完整分母、数量与比例 | 用相近扇区做精确比较；类别遗漏 |
| 同一批对象逐级留下多少 | 漏斗 | 同批口径、子集关系、分母 | 独立人群拼成漏斗；装饰宽度冒充数量 |
| 多个同尺度指标表现如何 | 雷达 | 统一量纲、范围、固定维度顺序 | 用多边形面积评分；不同单位直接拼接 |
| 两个维度和规模如何共同分布 | 二维坐标 / 气泡 | 轴含义、分界依据、面积映射 | 气泡半径与数量成正比；象限自动等于决策 |

`assets/visual-examples/` 提供从趋势到瀑布的 9 种合成示例、绘图脚本和预览。示例图之间不默认共用样本，具体来源由每张图的图注与数据文件说明。

新增饼、环、漏斗、雷达、二维坐标和气泡的输入及预览见 [常用模板](../assets/diagram-templates/README.md)。原有九种样例与新增六种布局共用主题，但仍各自保留正确的数据映射。

## 先锁数据口径

在图注或相邻正文保留足够复查的信息：

- 指标定义、单位和方向。例如延迟越低越好，成功率需说明分母。
- 时间范围、粒度、时区、版本、环境、样本筛选和去重口径。
- 原始数量、缺测和异常值处理；是否只统计成功请求。
- 聚合与派生公式。百分位不能通过平均各组百分位得到总体百分位。
- 比较是否同负载、同设备、同采样方式；不是受控实验时，不把变化归因于改动。
- 数据源与提取时间。敏感数据脱敏；合成数据只用于演示，明确标注。

没有真实数字时可以给空的数据需求表、定性图或明确的合成示例，不能把编造数字放进真实方案。来自截图的数字先核对刻度与精度，估读值注明不确定性。

## 趋势与比较

折线适合有顺序的连续变量。缺测保留断点；不等时间间隔按真实位置绘制。不同单位优先上下对齐的小多图，双轴仅在有充分理由且标明尺度时使用。

条形轴通常从零开始，因为长度承载数量。确需放大细微差异时，用点图或明确标出尺度的局部详图。对比图使用一致单位和范围，不用 3D、透视或渐变扭曲长度。

标注应指向真实观察。发布点或阈值有证据才画；“发布后下降”不自动等于“由发布造成下降”。平均值、P95、错误率可分别观察，不用一个均值代替分布。

折线在视觉上使用圆角线帽和连接点，优先交付 SVG，避免位图放大后发粗或出现锯齿。平滑曲线会改变点与点之间的形状，除非平滑方法、窗口和用途已经说明，否则只优化线条渲染，不插值改写数据。

## 分布与不确定性

直方图的 bin 选择会改变观感。比较组使用相同边界，保留完整尾部或注明截断与数量；需要查看尾部可补 ECDF 或对数轴。对数轴不能直接容纳零或负数。

ECDF 在每个观测值处累计概率，表达 `P(X ≤ x)`；有重复值时阶梯应合并或忠实递增。分位数采用什么算法需要在复现源中固定，不能靠鼠标估读。

ECDF 的阶梯是统计语义，不改成连续曲线。可通过减小线宽、使用圆角线帽、直接标注阈值和优先交付 SVG 改善观感，但不能用插值制造样本之间不存在的概率。

箱线图说明箱体为 Q1–Q3、中线为中位数、须线按何种规则计算。样例采用 1.5 IQR 范围内最远观测值，范围外点仍展示。小样本可以只画原始点，避免精致图形制造统计稳定的错觉。

误差棒必须说清是标准差、标准误还是置信区间，以及计算方法和样本单位。没有计算就不画。对重复测量、时间相关样本或分组聚合，不把每个点都当独立样本来推断显著性。

## 热力、组成与贡献

热力图用有顺序亮度的色标，缺测用单独图例，不涂成零值。相同指标跨面板使用相同范围；若做归一化，写清按行、按列还是全局。

组成图的部件应互斥且覆盖所声明总量。100% 堆叠必须给分母，比较占比时保留绝对量以防误读。需要精确比较中间类别时，改成分组条形或小多图。

瀑布图检查 `初值 + Σ增量 = 终值`。减少不一定是好事，色彩含义按指标说明；不要默认绿就是负数、红就是正数。解释存在未分配余量时单列，不能偷偷调数凑平。

## 比例、转化与多维表现

饼图或环图适合少数互斥类别，需要精确比较时优先条形图。扇区角度由数量计算；零值可以保留在图例，不能凭视觉补一个可见扇区。

定量漏斗的条宽对应人数，占比说明以首层还是上一层为分母。数量应非递增且来自同批对象；没有这些条件时用阶段列表。定性漏斗可用梯形表达收敛过程，但必须说明“不按数量比例”。

雷达图只比较同一量表下的维度，跨图保持维度顺序、轴方向和范围。面积随轴顺序变化，不能作为综合分。二维象限的分界需要依据；气泡的面积对应规模，不能用半径线性编码数量。点标注与边界冲突时重排或拆图，不能移动真实坐标来让画面好看。

## 渲染与交付

优先 Matplotlib、Vega-Lite、ECharts、VChart 等成熟绘图库。选择当前可用的一种即可，不为画一张图安装整套平台。工程关系可以手工 SVG，定量位置、尺度和统计量应由数据驱动计算。

交付数据或可访问的查询、转换/绘图脚本、图源与预览。记录实际库版本和字体；没有运行图表库，就不能宣称坐标已验证。PNG 便于离线阅读，SVG/PDF 便于编辑或印刷。

包内 Python 图表示例需要 Matplotlib 与 NumPy，仅在运行该示例时需要，技能文本、结构校验和已有图源不依赖它们。其他宿主可以用自己的绘图库复现相同数据映射；不要要求飞书账号或远程 API。

## 交付前复算

从数据独立检查总和、分母、单位、极值、分位数和瀑布闭合。对照最终渲染的轴、刻度、标签、色标和图注。检查是否有点被坐标范围裁掉、类别被漏掉，或标签通过四舍五入造成矛盾。

验证数值正确与验证结论成立分开。合成数据图的正确性只证明绘图方法，不证明真实系统性能。正式方案还需要可比数据和相应实验。
