# 五源怎么读 + 怎么防垃圾站抢占

> 定向扫的五个信息源，各自的读法与陷阱。复用手头联网检索能力，不打包爬虫。

## ① X（思潮层）
- 看什么：大佬/builder 在聊什么、什么概念在被反复提。抓"情绪+人群特定+还没被做成产品"的抱怨。
- 怎么读：搜话题词 + 高互动帖的评论区（真需求常在评论里，不在主贴）。
- 陷阱：通用 web 搜搜不到站内实时讨论。拿到的多是转载/二手。能用站内搜索/官方接口就用；否则靠高信号搜索词绕（见 search-queries.md）。

## ② GitHub Trending / Show HN（技术→可商业化）
- 看什么：正在涨 star 的仓、Show HN 上的自制工具——技术可行性已被验证，缺的是"包装成产品"。
- 怎么读：github.com 站内搜索 / Trending 页 / Show HN 列表；看 issue 区里"能不能加 X"的高频请求=现成需求。
- **陷阱（真踩过）**：通用 WebSearch 扫 "GitHub trending health" 首条常是垃圾博客转载（如 imtqy.com），真实仓只露一角。**优先用 github.com 站内搜索或 API**，别信通用搜的第一条。

## ③ Product Hunt（需求密度 + gap）
- 看什么：分类页里被反复要的东西、评论区里"这个不错但缺 X"=gap。
- 怎么读：官方分类页有 AI 汇总；可配 hunted.space 等第三方拿 upvote/评论量化信号。
- 陷阱：PH 榜单有营销刷量成分，upvote 高≠真需求强，交叉看评论质量。

## ④ 竞品差评 G2 / App Store（最强付费信号）
- 看什么：**1-3 星差评**。差评就是一份待办清单——用户已经在付费/在用，但不满意的地方就是切口。
- 怎么读：竞品名 + "reviews" / App Store 评论区按最新+按低星筛。
- 为什么最强：能写差评的人=真实付费/深度用户，比"我觉得会有人要"硬得多。

## ⑤ Google Trends（时机层）
- 看什么：**斜率，不是绝对值**。正在爬升的词 + Related Queries 里的 Breakout（突增）词。
- 怎么读：对比几个候选词的趋势线；Breakout 词往往是还没被做透的新兴需求。
- 陷阱：绝对搜索量高的多是红海；要找的是"斜率陡但绝对值还不大"的。

## 通用防噪
- 每源至少交叉 2 个搜索角度，别信单条结果。
- 垃圾站（内容农场/SEO 转载）一律筛掉，只认一手来源（原帖/原仓/原评论）。
- 拿不到站内真实数据时，如实标 `evidence: assumption`，别用二手转载充当一手证据。
