# 高信号搜索词库

> 全网搜验证阶段用。这些词能把"真实、带付费意愿的抱怨"从噪音里捞出来——因为说这些话的人，是在描述一个他愿意花钱解决、但市面没有的痛。

## 一级：直接暴露"缺供给"的抱怨句式（最高信号）
照抄去搜，把 `<领域>` 换成方向词，或不加领域全域捞：
- `"I wish there was an app"`
- `"is there a tool that"`
- `"why doesn't anyone make"`
- `"I'd pay for something that"`
- `"why is there no app for"`
- `"looking for an app that"` + `"but can't find"`

## 二级：暴露"现有方案不够好"（切口在差评里）
- `<竞品名> "alternative"` / `<竞品名> "too expensive"`
- `<竞品名> "wish it could"` / `<竞品名> "but it doesn't"`
- `"switched from" <竞品名>`（迁移=不满，看他们为什么走）

## 三级：暴露"钱已经在流动但没流向 app"（蓝海铁证）
- `<领域> "how much did you pay"` / `<领域> "worth the money"`
- `<领域> "spreadsheet"` / `<领域> "notion template"`（用户在用手工方案凑合=产品化机会）
- `<领域> "hired someone to"` / `<领域> "paid a coach"`（花钱找人做=可被软件替代）

## 用法
1. 先用一级词全域或按方向捞一批"缺供给"信号。
2. 命中某个方向后，用二级词挖现有竞品的差评切口。
3. 用三级词确认"钱是否真的在流动"——这是判蓝海的关键证据。
4. 每个命中都要回到源头拿**原话引用**，不能只写"有人说想要"。

## 语言
- 英语区信号最丰富（出海优先场景）；中文区补充搜小红书/即刻/V2EX 上的等价抱怨。
- 同一痛点跨语言都出现 = 信号更硬。
