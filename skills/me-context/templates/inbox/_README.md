# inbox/ · 候选记忆暂存

- 这里放**候选条目草稿**，不是正式档案。
- 两源都先进 inbox：
  - 源 A 访谈作答：当轮已确认的可直接 declared 落正式分片；未经确认的进 inbox。
  - 源 B 日常对话观察：一律先进 inbox。
- 用户说"整理下新记忆 / 更新档案"时，逐条 采纳/修改/否决/升级重要度；
  仅采纳项转 declared 正式落盘（带 supersedes / CHANGELOG）。
- **gate 永不加载 inbox；export 默认排除 inbox。**
- 草稿字段见 `_draft-template.md`。
