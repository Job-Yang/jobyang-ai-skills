# 视觉风格（去品牌、无固定吉祥物）与"表现力从哪来"

固定的是一套**视觉语言**，不是某个角色：白底/极浅灰、圆角卡片、橙色主点缀、
克制蓝/红/绿语义色、细描边线性图标、柔和微投影、大量留白、横版 3:2。
这套观感跨平台一致，且**不依赖任何吉祥物**。

## 先回答一个实测结论：画面"空、单薄"，锅不在吉祥物

用同一主题（AI 产出 vs 人看懂，差距在拉大）做过 A/B：
- **极简静物版**（打印机+放大镜，无角色）：干净但寡淡、两边体量没拉开，读完没有"追不上"的紧张感。
- **有叙事版**（机器人坐打印机、纸山堆到画面一半高、人踮脚仰头够不到、表情吃力）：表现力强、记忆点足。

差距**不是因为有机器人**，而是极简版丢了三样东西——

1. **体量悬殊没做出来**：纸山要真的高、要压到画面中线甚至更高；人/放大镜一侧要真的小、要够不着。
   两边尺寸差 3~5 倍以上，"失衡"才看得见。差不多大就是普通对比，不是张力。
2. **没有动作和情绪**：光有物体是静物画；要有"谁在做什么、什么状态"——机器飞速吐纸、人踮脚仰头、
   眉头紧锁、纸还在往上堆。情绪（吃力/从容、快/慢）才让人记住。
3. **画面太空、缺纵深和细节**：留白不等于空旷。要有前中后景、物体之间的叠压、
   纸带上的代码纹理、投影、动势线/速度线，让画面"满但不杂"。

**结论：默认可以没有吉祥物，但不能默认走极简静物。** 决定表现力的是"体量对比 + 动作情绪 + 纵深细节"，
角色只是承载动作情绪最省力的一种方式。所以给两档，按内容选，不绑定角色：

- **rich（默认，叙事版）**：把上面三样做足。优先用"物体本身的体量和动势"表达（纸山 vs 小纸叠、
  倾泻 vs 静止、箭头和速度线）；需要一个动作/情绪主体时，可放一次性、无标记的中性向导或真人剪影——
  **有角色是为了演动作和情绪，不是当 logo 摆着。**
- **simple（克制版）**：封面/极严肃场合/只要一个干净示意图时用。即便 simple，也要保住体量悬殊和动势
  （大 vs 小、箭头方向），不能画成两边差不多大的静物——那就退回"空"了。

## 表现力三件套（文生图提示词里要显式写，不能指望模型自己加）

| 要素 | 怎么写进提示词 |
|---|---|
| 体量悬殊 | 明确尺寸/占比："纸山堆到画面上半部、占画面高度约三分之二；右侧人物和放大镜只占约四分之一，明显够不到顶" |
| 动作情绪 | 主体+动词+状态："机器人手忙脚乱坐在飞速吐纸的打印机上；工程师踮脚仰头、皱眉、伸手够纸山顶" |
| 纵深细节 | "前景打印机、中景人物、背景纸山有叠压和遮挡；纸带上有彩色代码行纹理、柔和投影、向上飞的纸带和动势线" |

## 默认没有固定吉祥物 IP

- 信息图（尤其渲染器那类步骤/对比图）默认**不画角色**：靠卡片、箭头、线性图标、体量讲清。
- 文生图叙事版里即便出现人形/机器人，也是**一次性中性形象**，不要求读者跨图认识它；
  画面不出现任何 logo、品牌名、水印、机身文字标记。
- 不强制跨图复用同一角色。作者确实想要固定 IP 时，走"自定母版 + 图生图"（见下），母版是作者资产，不进技能包。

## 文生图常见翻车点（实测，写进提示词规避）

- **箭头方向**：想要单向就写死"只有一个朝右的红色实线大箭头，不要左端箭头、不是双向"。
  实测"虚线箭头"容易被画成左右都有箭头。
- **多余道具/服装**：不想让人物戴安全帽/穿工装，就显式写"普通休闲装、不戴帽子、无其它多余物品"，
  否则模型爱给"工程师"配安全帽反光背心。
- **文字**：图上只放 1 个短语（≤9 字）并逐字加引号，明确"除此不出现任何文字、字母、数字"；
  标签一多必糊——那种内容改走渲染器。
- **角色标记**：反复强调"机身干净、无任何 logo、字母、品牌标记、水印"。

## 去品牌文生图风格前缀（渲染器不走这套；仅文生图后端用）

基础前缀（不含角色）：

```
扁平化商务信息图插画风格，纯白到极浅灰圆角卡片背景，现代科技感、画面饱满有叙事张力、细节丰富、有纵深。
橙色为核心点缀色（高亮、对勾、能量），辅以克制的蓝色（方法/理性）、红色（问题/风险）、
绿色（通过/安全）；细描边线性图标、柔和微投影、物体间有叠压和动势。整体专业、克制、一眼看懂，
像高质量技术文章配图。画面不出现任何 logo、品牌名、水印或固定吉祥物。图中中文清晰无误。横版 3:2。
```

rich 版在基础前缀后**按需**追加一句角色描述（一次性中性向导，或真人剪影），并补齐三件套；
simple 版则把"画面饱满有叙事张力"换成"留白克制、元素精简"，但仍写清体量悬殊和箭头方向。

## 封面

封面是视觉钩子，不承载完整论证：一眼说清"讲什么、什么调性"。
左侧一个贴合主题、**带动作或体量感**的视觉元素（不要摆个静态图标了事），右侧/中部大标题（逐字加引号）
+ 一行克制副标题，留白干净、横版 3:2。封面文字少、是少数适合文生图的类型；`cover:true` 免过渡句，
但标题仍要和主题对得上、过 check_linkage 对账。

## 自定母版（作者想要自己的固定 IP 时）

技能不内置任何品牌形象。作者要固定角色：先生成一张干净白底、全身、无多余道具的定妆母版并确认，
存到作者指定位置（不进技能包）；后续用图生图/编辑，传母版 URL + 只描述新姿势/新场景，不重述长相。
形象规则由作者在自己的 brand pack 维护，技能本体保持中立。
