# 钢人抉择 · 先把两边立到最强，再决定

> **一句话理论**：批评或放弃一个选项前，先把它重建到它**最强、最合理、最难被反驳**的版本（钢人），而不是攻击它最弱的版本（稻草人）。
> 出自论证伦理的**善意原则（Principle of Charity）**与**钢人论证（Steelman Argument）**。
>
> **它解决什么**：人在两个都说得通的选项前犹豫，常见假动作是——把倾向方的优点和反方的弱点摆在一起，自以为权衡过了（确认偏误）；或两边各说一句好处就凭感觉选。本技能强制你先听完两边最强版本，再定位**真正的分歧**和**一个能翻盘的事实**。
> **它不做什么**：不替你拍板、不制造第三个"折中方"糊弄、不假装角色扮演出独立观点。

## 触发与边界

启用：存在两个或少数几个**已成形的选项**，且都有一定道理、用户在权衡。

| 情况 | 去向 |
| --- | --- |
| 没有现成选项，要从本质重推一条新路 | 第一性原理类重推方法（规划中；当前可用一般的"拆事实/假设/目标/约束重推导"代替） |
| 评单个想法值不值得做 | `opportunity-scorecard` |
| 核一条数据/说法真不真 | `claim-check` |
| 读一篇文章论证强不强 | `argument-reading` |
| 关键事实缺失、要查外部资料 | 需要时先调用 `outside-view` 取证，再回本技能收口 |
| 只有一个选项、或纯执行已定的决定 | 不启用 |
| 用户直接要"你告诉我选哪个"且责任在他 | 不替他决定；做完结构化后把决定权交还 |

选项由谁给：
- 用户已给出 A/B：直接进入协议。
- 用户只描述纠结、选项不清：先用一两轮澄清把候选**显式列成两个互斥选项**（一次问清最影响结论的），再开始；不要自己脑补第三个选项凑数。
- 确实存在三个实质不同的选项时，可对每个做"最强版本"，但超过三个先帮用户收敛，否则是在做选项罗列而非抉择。

## 钢人协议（按顺序，不许跳步）

### 1. 重述抉择

用一句话写清：**要决定什么、A 是什么、B 是什么、目标和硬约束是什么**。选项必须真正互斥、在同一目标下可比；若发现两个选项其实在回答不同问题，先纠正问题定义。

### 2. 把每边立成钢人（核心步骤）

对 A、B 分别写最强版本，每边必须包含五项：

1. **最强理由**：支持这一边最有说服力的论证，用它支持者会用的最好方式表达，不许用"有人可能觉得……"式敷衍。
2. **适用条件**：它在什么前提下确实是更优解。
3. **最大收益**：选它最好能拿到什么。
4. **最大风险与代价**：最诚实的坏处，不回避。
5. **最难回答的反对意见 + 当前最好回应**：主动找最锋利的反方一击，并给出这一边能给出的最强回应；答不上来就如实标注"此处无回应"，不许编。

钢人合格线：写出来的 A 方最强版本，**要让真正支持 A 的人看了觉得"这确实是我的意思，而且说得比我好"**。如果明显在树稻草人（用反方弱论证反衬倾向方），打回重写。

### 3. 让两边互相质疑，找三样东西

钢人各自立完后，让最强版本对撞，输出：

- **共同认可的事实**：两边其实不吵的部分（很多犹豫在这里就消失一半）。
- **真正的分歧**：不是表面选项不同，而是背后**哪个假设、价值排序或约束判断**不同。
- **关键变量**：最可能改变结论的 1–2 个变量（某个事实、某个前提、某个未来条件）。

### 4. 只问一个翻盘问题

把"还缺什么信息"收敛成**一个**最可能改变结论的问题/待验证项：

- 这个问题的答案若为 X → 选 A；若为 Y → 选 B。写清这个映射。
- 一次只问一个，且必须是"能翻盘"的；问了不影响选择的问题不问。
- 能查的事实（价格、性能、政策、数据）先去查（若宿主具备检索则调用，或引导用户查），别用纯对话拖；查不到就标注为待验证假设。

### 5. 交还决断

在用户回答翻盘问题 / 补到事实之后，给出：
- **条件化判断**：在什么前提下推荐哪个（不是替他拍板，是把选择规则讲清）。
- **推荐选项 + 理由 + 第一步行动**：若关键变量已明朗，可以明确推荐；若仍取决于用户价值偏好（如风险厌恶程度），说明"这个事实层面已无分歧，剩下是你的价值选择"，再给倾向供参考。
- **退出/止损条件**：选了之后出现什么信号说明选错了、该回头。
- 多候选时每个候选都必须是用户真心愿意走的 A 计划，**不许留凑数的备胎**。

## 防失败模式（硬规则）

- **禁止稻草人**：每边必须呈现其最强理由和最强反方回应；用弱论证凑数直接重写。
- **禁止假平衡**：证据明显一边倒时不许"各打五十大板"；如实说明哪边更强、强多少。钢人是"公平呈现"，不是"两边都对"。
- **禁止假独立**：本技能不做"请三位专家发言"式角色扮演——同一模型扮演的多角色高度相关，只会制造仪式感。价值在于**强制输出结构**（最强版本/真分歧/翻盘变量），不在表演多个人格。
- **禁止虚构**：最难反对意见的"最佳回应"找不到就写无回应；关键事实没查就标待验证，不编造数据或来源。
- **禁止中庸和稀泥**：不默认推出"A 和 B 结合一下"的第三方案，除非它真能同时满足两边目标且不付双倍代价。
- **禁止无限追问**：最多一个翻盘问题；用户信息已经足够时直接给条件化判断。
- **决定权归属**：事实与推理归本技能，最终价值取舍和拍板权在用户；结论必须以"在……前提下"的形式保留边界。

## 可感知信号（触发宣告与收口）

命中本技能并完整走流程时：

- **开头一行轻量宣告**：`〔思考：钢人抉择〕把两个选项各自立到最强，再找真正分歧和那个能翻盘的事实`，让用户知道是哪个技能在起作用、这轮要做什么。一句话快答或顺带提一句时不贴标签。
- **收口自检多答一句**：在结论后用一句话说明"这轮让你的下一步具体改变了什么"（例如把纠结缩成一个待查事实、给出一个本周可做的动作、指出一条不该照搬的点）。读完仍不知道下一步该干嘛，视为本次失败，重做。

好坏的用户体感判别与反馈话术见仓库 `docs/SKILL-QUALITY-CARD.md`。

## 输出骨架

```text
抉择：在【目标与约束】下，A …… vs B ……
A 的钢人：最强理由 / 适用条件 / 最大收益 / 最大风险 / 最难反驳与回应
B 的钢人：（同上五项）
共同事实：……
真正分歧：背后不同的假设/价值/约束是 ……
关键变量：……
一个翻盘问题：……（答 X→A，答 Y→B）
条件化判断与推荐：……（事实分歧 vs 价值取舍分开写）
第一步行动 / 退出条件：……
```

简单二选一可压缩篇幅，但钢人五项、真正分歧、翻盘问题三件核心内容不能省。

## 交付前自检

- [ ] 两边都写成了支持者会认可的最强版本，没有稻草人。
- [ ] 每边都包含最难反驳意见及其最强回应，答不上的地方已如实标注。
- [ ] 找到了共同事实、真正分歧（背后的假设/价值差异）、1–2 个关键变量。
- [ ] 只收敛出一个能翻盘的问题，并写清答案如何决定 A/B。
- [ ] 没有假平衡、没有硬凑第三方案、没有角色扮演、没有编造。
- [ ] 最终把拍板权交还用户：事实结论与价值取舍分开，给了第一步与退出条件。
