# 关键事实核查规程

## 核查范围

只核查会实质影响核心结论且可验证的关键事实：统计数字、引语、事件时间线、因果性事实主张、关键案例和来源声明。严控检索预算：优先挑最关键的 **3–5 项**高影响事实验真，每项最多 **1–2 轮**可靠检索；遇工具报错、付费墙或连续无有效一手结果即止并如实标状态，不对所有细节做无差别检索。

## 执行要求

具备可靠外部检索能力时，对高影响事实做实际核查，而不是只生成待办清单。先判断「该事实不成立，核心结论会怎样变化」，再优先核查影响最大的事项。

无法访问可靠来源或任务不允许外部检索时，明确写「未执行外部核查」或「待外部核查」；只有已检索过但现有来源仍无法可靠判定时，才写「证据不足」。不得用模型记忆、作者自述、匿名转述或同一篇文章内的重复表述替代外部核查。宿主不具备检索能力时，本技能降级为纯文本内分析，并显著标注外部验证缺失。

## 来源要求

优先一手、权威、可追溯来源；二手媒体仅作线索；争议事实尽量用相互独立的来源交叉验证。每项核查记录来源标题、发布机构、发布日期、可访问链接和访问日期；时效性主张同时核对事件时间、文章发布时间和核查来源时间。禁止以省略号截断 URL 路径。

- 只有链接直接指向政府部门、官方机构、涉事平台、原始数据库、原始报告或原始发布者，才能写「官方原始来源支持」。
- 只找到媒体/公众号等二手转述时，来源性质写「媒体转述官方数据」，不得标为官方原始来源；无法回到官方原文时相应降低结论强度。
- 一个核查项多个来源时，每个来源单独成行，不合并名称只给一个链接。
- 来源引用另一来源时，尽量追溯到原始数据、文件、讲话或记录。

## 核查状态（五级裁决 + 两类过程状态，与 `claim-check` 完全统一）

五级可信度裁决：
- **已证实**：可靠一手/独立来源直接支持，口径和时间范围相符。
- **基本成立但需收窄**：方向正确，但原说法在范围、程度、时间或条件上被夸大，需限定口径。
- **存在争议**：可靠来源之间有实质冲突，需列出分歧点。
- **证据不足**：已实际检索，但现有来源无法可靠判断。
- **明显错误**：可靠来源与该主张直接冲突/反证。

两类过程状态（不算裁决；处于此二状态时结论只能暂挂，不许给肯定档）：
- **待外部核查**：值得核查，但当前条件（权限、付费墙、离线或工具报错）无法完成。
- **未执行外部核查**：本轮没有做任何外部检索。

## 文本内证据 vs 外部验证

外部事实核查与文本内部分析分开呈现。作者陈述只能证明「作者这样说过」，不能单独证明陈述为真；匿名转述、个案、历史类比、预测、作者观察可作文本内论据，但必须保留证据类型，不能标「外部验证通过」。

## 与 `claim-check` 的词汇对齐

本规程直接沿用上述同一套「五级裁决 + 两类过程状态」词汇（不再另造"支持 / 部分支持 / 不支持"等近似词），与 `claim-check` 交叉调用时不发生口径换算误差。

## 冲突与不确定性

来源冲突时说明冲突点、来源独立性和可能原因。来源只能证明相关事实但不能证明文章的因果推断时，明确区分「事实存在」与「因果解释成立」。多个来源重复引用同一个原始说法，不视为相互独立的交叉验证。
