# 论证重建规范

## 目标

把散落的文本重建为可审查的论证链：结论 → 关键理由 → 证据 → 推理连接 → 隐藏前提 → 成立边界。重建不是找错，而是让作者真正的说服路径变清楚。先重建作者最强合理版本，再评价。

## 核心论点卡

完整模式对影响总判断的核心论证逐条建卡。每张卡包含：认识状态、结论、原文定位、理由、证据、证据类型、推理连接、隐藏前提、成立边界。原文没提供的环节明确写「原文未提供」，不替作者悄悄补齐后再批评其不完整。

原文定位用页码、标题与段落，或 8–20 字可搜索原文短语，让读者能快速回原文核对，不用「文章前半部分」「作者提到」这类模糊描述。关键引语与数据直接抽取精确出处。

## 识别对象

- **核心问题**：文章试图回答的主要问题。
- **核心结论**：作者希望读者接受的判断、解释、预测或行动建议。
- **关键理由**：支撑核心结论的主要依据。
- **推理连接**：理由为什么能推出结论。
- **隐藏前提**：作者没明说但论证成立所依赖的条件。
- **成立边界**：结论适用的对象、时间、地点和条件。

## 证据分类

至少区分：一手数据、权威文件、原始记录、二手报道、专家判断、匿名转述、个案、作者观察、历史类比、预测、原文未提供。

「原文出现了某句话」只能证明作者或信源这样陈述过，不等于陈述内容已被外部证实。作者自述、匿名企业家转述、经验观察、历史类比和预测可以参与论证，但必须说明它们能支持什么、不能支持什么；只有经独立外部来源核验的内容才能标外部验证通过。

## 认识状态

- **原文陈述**：作者直接说出的内容，附原文定位。
- **合理重建**：原文未完整说出、但可由上下文推出的连接和前提。
- **分析评价**：对证据和推理的判断。
- **增强建议**：为强化论证额外提出的内容，不能冒充作者原意。
- **外部验证通过**：有可访问来源支撑且记录了来源信息的核查结果。

## 重建要求

先复述作者最强合理版本，再进入评价。不挑作者最弱的表达攻击，不把作者未讨论的所有问题都当缺陷；只有遗漏会实质影响核心结论时才列为完整性问题。

每项重要批评按「原文定位 → 具体推理断点 → 为什么影响结论 → 影响范围与置信度」展开。谬误名称只作最后辅助标签，不能替代对推理断点的解释。
