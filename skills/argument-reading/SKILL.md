# 论证精读 · 先公平重建，再严谨评价

> **方法论**：**善意原则（Principle of Charity）＋ 论证分析**。先把作者的论证重建到它最强的合理版本（不攻击稻草人），再按统一证据标准评价。批判不是找错，也不是替用户裁定立场。
>
> **它解决什么**：一篇文章看起来很有道理，但论证链是否完整、证据是一手还是转述、哪些是隐藏前提、哪些结论外推过度——读完输出一张能回到原文核对的**论证地图**。
> **与邻居的边界**：一条说法验真 → `claim-check`；两方案抉择 → `steelman-choice`；开放决策调研 → `outside-view`。本技能只处理**一篇完整文本的论证质量**。

## 输入与不启用

输入可以是粘贴正文、网页内容、PDF、DOCX、Markdown。材料截断/OCR 受限要先披露。

不启用：只要摘要/翻译/润色；学术论文的专业评审；要求站队、煽动情绪、虚构事实证据；纯单条说法（→ claim-check）。

## 路由（自动判断，不必先追问）

- **文本协议**：新闻/事实报道用「信息协议」；评论/观点/演讲/长帖用「论证协议」；营销/宣传/倡议/行动号召用「说服协议」。混合文本按主导核心结论的机制选，必要时组合，不为覆盖协议重复分析。
- **深度**：默认完整；用户要简短或文本很短用快速。
- **阅读目标**：默认阅读判断；用户拿自己的文章来用作者自检；明确要据此行动用行动转化。

协议检查重点、论证重建与评价量表见 `references/protocols.md`、`argument-reconstruction.md`、`evaluation.md`、`fact-checking.md`，需要对应环节时读取（快速模式只读相关小节，不必全部加载）。

## 核心流程

1. **标准化输入**：提取正文与元数据，保留标题、引语、表格、脚注；建立页码/章节/原文短语定位，披露缺失与截断。
2. **理解文本**：识别议题、核心结论、目的、受众、语境。多议题文本分别建图，不强行归并。
3. **重建论证**（先善意）：对关键结论写「理由 → 证据 → 推理连接 → 隐藏前提 → 成立边界」，区分原文陈述、合理重建、增强建议。参考 `argument-reconstruction.md`。
4. **评价与拓展**：最强之处、关键断点、替代解释、遗漏视角；对政策/商业方案/行动建议额外分析失效条件。不为凑栏目制造问题。
5. **核查关键事实**：只核查会实质改变核心判断的可验证事实。区分文本内证据与外部验证；具备检索能力时实际核查，未核查不得用"支持/已验证"措辞。规程见 `fact-checking.md`。
6. **形成判断**：值得接受的、需要保留的、无法判断的，分开给。作者自检侧重补证/限缩/改写；行动转化只给一个优先行动加它的验证问题。
7. **输出论证地图**：默认在对话内给结构化结果；用户要文档时写成 Markdown 文件交付到其指定位置（不绑定任何特定文档平台）。快速模式只保留核心观点、最强依据、最大疑点、核查状态。

## 输出结构

完整模式：

```text
一句话判断：核心价值 + 最关键限制 + 成立条件
议题与结论：议题 / 核心结论 / 目的 / 受众
核心论点卡（每张）：认识状态 · 结论 · 原文定位 · 理由 · 证据 · 证据类型 · 推理连接 · 隐藏前提 · 成立边界
有说服力之处：强项 + 原文依据 + 为什么成立
需保留判断之处：问题 + 原文定位 + 推理断点 + 对结论的影响 + 置信度
关键事实核查：待核查主张 / 核查状态 / 来源性质 / 来源与日期 / 对结论的影响
文章没告诉你的：遗漏视角 · 替代解释 · 反方最强回应
如何让论证更强（钢人，仅确有实质价值时）
接下来值得核查/思考的 2–4 个高价值问题
行动转化（仅该目标）：一个优先行动 / 失效条件 / 验证问题
```

快速模式：核心观点 / 最强依据 / 最大疑点（含原文定位）/ 核查状态 / 下一步核查。

## 可感知信号（触发宣告与收口）

命中本技能并完整走流程时：

- **开头一行轻量宣告**：`〔思考：论证精读〕先善意重建这篇文章的论证链，再评价证据、前提和断点`，让用户知道是哪个技能在起作用、这轮要做什么。一句话快答或顺带提一句时不贴标签。
- **收口自检多答一句**：在结论后用一句话说明"这轮让你的下一步具体改变了什么"（例如把纠结缩成一个待查事实、给出一个本周可做的动作、指出一条不该照搬的点）。读完仍不知道下一步该干嘛，视为本次失败，重做。

好坏的用户体感判别与反馈话术见仓库 `docs/SKILL-QUALITY-CARD.md`。

## 防失败模式（硬规则）

- **摘要冒充批判**：只复述内容不算精读，必须重建推理连接并评价其影响。
- **阅读即找错**：先完成理解、善意重建和强项识别；允许"未发现实质问题"，转报成立条件与信息边界。
- **稻草人**：批评前必须先给出作者最强合理版本。
- **谬误标签堆砌**：先讲具体推理断点与影响，标签只作最后辅助；有争议就说成立条件。
- **事实核查幻觉**：无可靠来源时写"待外部核查/证据不足"；官方源与媒体转述严格区分；多源转载同一上游不算交叉验证。
- **立场投射与虚假平衡**：对赞反双方用同一证据标准，不凭作者身份判真伪，也不用"双方都有问题"制造平衡。
- **钢人冒充原意**：增强建议必须明确标注，不能说成作者本意。
- **节选代替全文**：只读到部分材料时显著标注范围并降低结论强度。
- **平台中立**：不引用任何宿主专属工具或平台技能名；需要的外部能力一律写"若宿主具备则用"。

## 交付门槛

- 核心判断能回到原文定位（页码/标题段落/可搜索短语）。
- 论证链缺失环节已明确标注，没有替作者悄悄补齐。
- 证据类型没有把作者陈述误当外部证据。
- 关键核查结论可由独立来源复核；未实际核查的不写成已证实。
- 不满足时先补证或降级结论强度，再交付。
