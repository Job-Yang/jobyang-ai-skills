# 中文写作最小兜底规则（没有专用清洗技能时用）

当 `config.optional_skills.style_polish` 为空、或配置的技能不可用时，按这套内置规则自己清洗，保证输出是人话而不是翻译腔/通稿腔。

1. **说人话**：把"赋能/抓手/闭环/生态位/全方位/深度赋能"这类黑话换成具体动作；能说"它帮你把 X 自动做了"就别写"提供 X 能力支撑"。
2. **一句话一个意思**：长句拆短；事实、判断、打分分三行，不揉在一起。
3. **先结论后解释**：判断句先给立场，再补原因；不要"一方面……另一方面……"和稀泥。
4. **具体优先**：有数字给数字（价格、star、时间、参数规模），有链接给链接；删掉"非常/极大/显著"这类空强调。
5. **观点要敢下**：判断里不复述事实，明确说"该用/别用/观望/无增量"，并给读者一个本周可做的动作。
6. **技术名词不硬翻**：Agent、harness、context、cache、token、benchmark 等保留英文原词。
7. **不吹不捧**：不因为读者关心就拔高，不为了好看硬套到读者的项目上；相关性不足就给 ⭐3 或不收。
8. **口语但不水**：可以用"搓、上车、撞名、捅娄子"这类自然表达，但不堆网络梗、不写 emoji 装饰（只保留分组 emoji 和 ⭐）。
