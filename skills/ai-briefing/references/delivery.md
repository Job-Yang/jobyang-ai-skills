# 交付规则（双保险）

目标：无论渠道或文档出什么问题，读者当天一定看得到完整早报。

1. **主交付**：按 `config.delivery` 写到指定文档。
   - 每天在文档**最顶部**新增一节 `YYYY-MM-DD 周X · AI 早报`，最新在最上。
   - **历史内容只读不改**，不重排、不覆盖、不删旧节。
   - 文档不存在时：如果配置了创建能力则按标题新建并把 doc_url 回写配置；没有创建能力就降级为 Markdown 文件，不反复尝试。
2. **兜底交付（强制）**：不管文档成没成功，本次任务输出里都要附**完整早报正文**。
3. **失败不静默**：网络/登录态/X/文档任一失败，在文末"渠道状态"如实写；但早报照常交付，不允许只报错不出内容。
4. **文末固定汇总**：
   - 今日 3 条头条各一句话；
   - 文档链接（成功时）或降级说明；
   - 各渠道真实获取状态（X 走的哪一档、是否成功；GitHub 用的实时抓取还是离线；PH/媒体是否正常）。

## 本地文件兜底（无云文档时）

把渲染好的 Markdown 存为 `ai-daily-YYYY-MM-DD.md`（放在宿主约定的工作目录），并在对话里给出文件与全文。文件名带日期、不覆盖历史。
