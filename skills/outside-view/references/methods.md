# 方法依据与证据审查

只在以下情况读取本文件：

- 需要解释或审计 `outside-view` 的设计依据。
- 高影响任务存在难以消解的证据冲突。
- 需要设计一套完整的 `DEEP` 调研。
- 维护本技能。

普通 `DIRECT` 和 `QUICK` 任务不要加载本文件。

## 外部视角的职责

能力分成三层：

```text
具体任务：技术方案、产品决策、大型计划
             ↑
outside-view：发现认知缺口、组织外部视角、裁决冲突、判断适用性
             ↑
基础工具：搜索、RAG、知识库、论文检索、源码和运行证据
```

搜索回答“哪里有材料”，RAG 回答“哪些内容与问题相关”。`outside-view` 继续回答：

- 当前判断缺少哪些外部视角。
- 这是稳定共识、条件性经验还是仍有争议。
- 不同结论为什么冲突。
- 哪些信息适用于当前约束。
- 外部输入应保留、修正还是推翻原判断。

## 信息价值

检索前先判断额外信息能否改变决定。可用以下问题约束：

- 哪个未知项会改变推荐、范围、风险或执行顺序？
- 判断错误的损失是什么？
- 获取信息需要多少时间、延迟和上下文？
- 搜到后是否真的能采取不同动作？

如果额外信息不会改变行动，检索价值接近零。高影响只提高验证要求，不自动提高检索量。

## 证据角色

按角色寻找材料，不按数量凑来源：

- **锚点**：官方、一手或原始定义。
- **实证**：数据、实验、真实案例或可复现结果。
- **反方**：失败案例、限制、批评和相反结论。
- **参照系**：与当前任务真正相似的既有案例和结果分布。

并非每个 `DEEP` 都需要四类齐全。只取与待验证主张相关的角色。

## 证据账本

复杂冲突中，可在内部记录：

| 字段 | 要回答的问题 |
| --- | --- |
| 主张 | 材料具体支持、反对或限定什么 |
| 来源角色 | 锚点、实证、反方、参照系或背景 |
| 作者与发布方 | 是否有相关权限、专业能力或利益关系 |
| 时间与版本 | 对应哪个时间、版本和上下文 |
| 直接性 | 直接回答当前问题，还是跨场景类推 |
| 方法 | 是否有数据、样本、过程和复现依据 |
| 独立性 | 是否转载或共同引用同一上游材料 |
| 适用范围 | 对象、规模、地域、团队和目标是否匹配 |
| 局限 | 偏差、缺失、不精确和未覆盖部分 |

权威性、直接性、方法质量、独立性、时效和适用范围是不同维度。不要用一个总分掩盖其中的短板。

## 竞争假设

存在真正冲突时，至少保留两个仍然合理的解释。对关键证据逐条问：

- 这条证据是否也能被其他解释说明？
- 哪条证据最能区分两个解释？
- 什么结果会推翻当前倾向？
- 最关键证据失效后，结论是否反转？

这套做法用于暴露假设和找反证，不把矩阵或计分当成证明。

## 参照类

大型计划和工期估算优先看相似项目的实际结果分布，再根据当前差异谨慎调整。参照类本身也要审查：

- 项目规模和复杂度是否可比。
- 团队能力和组织条件是否相近。
- 是否只收录成功案例，遗漏停项和失败。
- 当前项目是否存在足以脱离分布的明确差异。

已提供足够可比的历史数据时，应直接使用，不再为了“外部视角”重复检索。

## 方法来源

本技能吸收并改写了以下方法：

- **Adaptive-RAG**：按问题复杂度在不检索、单步检索和多步检索之间选择。
  https://aclanthology.org/2024.naacl-long.389/
- **Self-RAG**：固定加入检索结果可能降低效果，需要按需检索并检查支持度。
  https://openreview.net/forum?id=hSyW5go0v8
- **Sufficient Context**：区分“模型没用好材料”和“材料本身不足”，证据不足时克制回答。
  https://openreview.net/forum?id=Jjr2Odj8DJ
- **Astute RAG**：检索结果可能不完整、误导或互相冲突，需要带来源意识地整合。
  https://arxiv.org/abs/2410.07176
- **SIFT**：暂停、调查来源、寻找更可靠覆盖，把主张追溯到原始语境。
  https://nic.pressbooks.pub/delvingintowriting/chapter/sift-method/
- **Analysis of Competing Hypotheses**：并列合理解释，重视反证和能区分解释的证据。后续研究指出 ACH 缺少充分实证支持，因此这里只把它用作检查假设的脚手架。
  https://www.nationalacademies.org/read/13062/chapter/8
  https://www.tandfonline.com/doi/full/10.1080/08850607.2023.2243803
- **GRADE**：从偏差风险、不一致、间接性、不精确和发表偏差等维度评价证据确定性。
  https://training.cochrane.org/handbook/current/chapter-14
- **Value of Information**：额外信息可能改善决定，且收益高于获取成本和延误时，才值得继续收集。
  https://www.pmi.org/learning/library/decision-analysis-approaches-project-value-3735
- **搜索饱和与 SAFE 停止启发式**：停止要平衡遗漏风险和继续筛选成本。
  https://pmc.ncbi.nlm.nih.gov/articles/PMC10908130/
- **Outside View / Reference Class Forecasting**：估算从相似项目结果分布出发，再按当前差异调整。
  https://www.tandfonline.com/doi/full/10.1080/09537287.2025.2578708

这些方法提供检查视角，不构成必须逐项执行的清单。现场直接证据仍然优先。
