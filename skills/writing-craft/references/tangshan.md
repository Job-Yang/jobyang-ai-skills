# 汤山专栏长评分支（tangshan）· 结构洞察与周期推演

> **定位与原则**：带克制冷静的专栏分析感（**绝非情绪化科技自媒体腔或二手俗套金句**），从激励博弈、制度结构与历史周期切入，把行业、组织、社会或技术现象写成冷峻通透的深度长评与推演。本手册是**思考放大镜，不是写作紧箍咒**；所有技法均按需取用，若某项修辞或类比反而抬高理解成本，直接省掉。

## 0. 出稿四条硬底线

1. **标题级数**：首行固定 `# 主标题`，主章节用 `3–4` 个简短 `##` 路标（`4–10` 字）；**绝不用 `##` 当主标题、绝不用 `###` 替代主章节、绝不单开 `结语` 空壳尾节**。
2. **零虚构数字、量级与盈利背景**：开篇直入输入给的事实，输入未给的任何金额、倍率、用户规模、时间跨度或盈利断言一律不编（不写未证实的宏大开场或拍脑袋数字）。
3. **主体拆清与概念准确**：把不同商业主体的成本结构与盈利口袋分开拆透，不混为一谈；不把同一人的双层因果判断错写成「矛盾心态」，不错用经济学或博弈名词（如不把非博弈结构叫「囚徒困境」、不把成本倒逼或交叉补贴错称「暴利」「庞氏」）。
4. **拒自媒体套话与轻洗收尾**：远离悬浮大词与二手俗套修辞（如奇点/荒原/乌托邦/硅基/内卷/降维打击/旧船票/硬核解法/翻开序幕）；交稿前逐句核查病句、中英文空格与单位重复，并过 `haohao-shuohua` 轻洗档（保留连贯散文与简短 `##` 路标，不做大段压缩）。

## 1. 核心思维引导（锦上添花，零配额要求）

- **冷开直切，先把反常摆上桌**：第一句直切具体事实或反常冲突，**避免导语连写两三段把同一组背景换词复述一遍**。
- **先认账再翻前提，追出一以贯之的底层力学**：先给主流观点或当事方合理的空间，再挑出其中被顺手带过的隐含前提；不只交代「机制是什么」，多追一层「在真实目标函数、认知/物理带宽或成本结构下，这种反常形态为何必然长成这样」，尽量用同一条底层力学贯通前后半段。
- **再穿透激励私账、双边错配与载体博弈**：把这条力学放回真实的人、组织与长期演化里——批判前先退半步体谅当事人的现实处境（「换谁坐那个位子也难办」），撤掉骂坏人的廉价靶子，拆清谁拿即时收益、谁扛远期代价、双边错配与产品载体形态背后的博弈差（例如固定费的消费端道德风险 vs 按量费把模型试错风险转嫁给用户；新形态为何拆穿旧界面/入口护城河；不同上游玩家的盈利口袋各自在哪）。
- **推到逻辑终点，收在刃口**：把成立边界自然融进分层论证，顺着前文推实的结构矛盾**落在新推出来的冷峻判断或开篇张力的回响上即停**——不要回头复述主标题，不在收尾另起「综上所述」式复述，也不退回推翻前文瓶颈的软着陆。
- **武器库按需取用**：日常建模、话术翻译、反常算账、二阶翻面与历史对照均属可选放大镜，贴题顺手取 0–2 件点睛，不按清单硬凑。

## 2. 借例与比喻的降维红线（高于一切修辞）

借生活比喻或历史参照只有一个合法目的：**帮读者一秒看懂原本抽象复杂的脉络，显著降低理解成本**。出手前过三问，过不了就直接删掉：

1. **真降维吗**：所借事物比本体更简单、读者一眼就懂吗？（避免拿陌生复杂的金融或专业机制去解释另一个领域。）
2. **真同构吗**：核心因果一致吗？（不把无心机制漂移错比成恶意做局，不拿彼此独立的物品硬比强依赖链。）
3. **够克制与不照搬吗**：全篇留 `1–2` 个最准的锚点就够；宁可零比喻、零跨界历史用本领域精确语言直白讲透，不为了显风格硬凑升维例，也不把参考手册里的示范比喻或示范结论照搬进当前选题。

## 3. 语体、段落与版式自适应（去戏服化，去汇报 PPT 化）

- **连贯散文与完整分节骨架**：深度长评靠因果推进、长短句差与自然分段维持张力（完整长评通常 `1,800–3,500` 字，不压缩成三段干瘪提纲，也不把末尾写成每节一套「引子 + `1. 2. 3.` 要点清单 + 小结」的咨询白皮书）。列表只留给全篇确有 `1–2` 处并列硬事实或清晰分水岭、列出来明显比段落省力的地方。
- **硬核科技 / 工程 / 数学推演**：保持冷静、精确、克制；长密论证段与 `1–2` 句短转折段错落交错，单段控制在 `100–200` 字保持呼吸，长链算账多用短分句断气，少把多项并列用分号硬揉进长定语单句，必要时用一句独立短段或单句引用钉住全篇最核心的洞见，避免清一色等长方块段，不硬拗市井江湖腔。
- **社会 / 商业 / 职场泛议论长评**：更重连续叙事张力，贴题时自然带出冷幽默与生活实感动词，写普通人处境冷而不毒、零煽情白描。
- **共守底线**：直接从具体事实与反常切入，不写「此事引发两派分歧」类套话开篇；不生造带引号或加粗的唬人术语，远离工整对称的公文排比套壳与反问收尾；正文引用文末来源时保持角标对齐。

## 4. 事实、术语与因果双保真（冲突时先保真）

1. **忠于输入事实，不脑补、不造假对立、严禁虚构量级**：按输入原貌陈述人物观点与范围，不把同一人物或观点的两层意思错拆成「对立两派」，不凭空添入输入里没有的地域对立（如无中生有写「中外分歧」）。**不编造未给数量、时间尺度与夸张对比**，人名、专有名词与外文术语保持原词或公认译名，不自造音译、不把并列术语粘连错拼。
2. **机制、角色与前后逻辑自洽**：不同商业主体的成本结构与盈利口袋分开拆清；硬核技术先用精准平实的语言把原理、适用前提与各方职责边界交代清楚；检查前后文断言不自相矛盾（前文指出的局部手段缺陷，后文不改口包装成完备保证），也不把随人变化的开放问题夸大成可穷尽、零缺陷的封闭题。
3. **数据与史实带口径和跨度**：保留原始数值、单位（如桶与吨、同比与环比）与来源，历史与典籍年代、朝代、篇名可追溯，多阶段演变写清时间跨度，未知细节保守处理或标待核，不脑补数字。
4. **交稿前清一遍冗余、病句与轻洗**：删掉相邻两句换词复述的啰嗦句与叠词/单位重复，核对笔误与衔接，并过 `haohao-shuohua` **轻洗档**（保留连贯散文与简短 `##` 路标，不做破坏节奏的大段压缩）。
