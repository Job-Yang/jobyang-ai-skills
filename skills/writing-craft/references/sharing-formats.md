# 口头分享（talk）与演示分镜（slides）专项要点

> 仅在 `sharing` 分支需要产出「演讲口播稿 `talk`」或「幻灯片分镜 `slides`」时按需查阅；普通图文博客不必读本文件。

## 0. 口播与分镜四条硬底线

1. **零私有事实脑补**：屏幕锚点与 `Speaker Notes` 只写「输入原始事实 + 公开工程机理」；输入没给过的耗时降幅、百分比换算、线上客诉/事故定级、内部日志系统名、具体天数或时间跨度外推一律不编，**严禁把已拦下的局部缺陷偷换或拔高成线上重大事故**。
2. **禁抄本手册示范词**：切勿将本手册示范里的数字、案例或用词（如示例中的时长、无人值守等）照搬进实际分享。
3. **不喊礼貌空套尾**：末页落回可带走行动或 Q&A 开放问题，不写「今天的分享就到这里，谢谢大家」。
4. **交稿前逐页回读**：核对每页 `Speaker Notes` 标题拼写（防乱码错字）、数字口径闭合（已完成 + 未完成 = 总数，不随口编比例）与中英文空格。

## 一、口头分享稿（talk）

口播听众不能回翻页面，核心诉求是**耳朵一遍听懂、节奏抓得住、带走一句话**。

- **篇幅按分钟倒推**（中文口播语速约 `200–240` 字/分钟）：
  - `10` 分钟分享 ≈ `2,000–2,400` 字；
  - `15` 分钟分享 ≈ `2,800–3,500` 字；
  - `30` 分钟分享 ≈ `5,500–7,000` 字。
- **开场不寒暄**：第一句直切现场问题、真实成效或反差；用一句话交代「今天讲多久、听完能带走哪件具体的事」。
- **显式口播过渡与回扣**：
  - 节与节之间替听众把下一问顺口问出来再答（「前面把编译接通了，那为什么跑到运行态还是不放心？」），别连续两节叠排比问句。
  - 讲到中段把核心主线词或那句主判断温和回扣一次，帮走神的听众重新对齐。
- **为耳朵写短句**：一口气念得顺、不念复杂公式签名与长三列表（公式/明细放演示页或附文档，口播只讲结论和直观对比）；报出硬数字后紧跟一句大白话解读（「14.6 小时无人值守，差不多相当于放它在夜里跑完一整轮重构」；仅作数字大白话翻译示范，切勿照搬其中数字或「无人值守」等词进实际稿件）。
- **克制收尾**：用 `2–3` 条能动手的收获或一句冷静结论收口，必要时留一个引发讨论的 Q&A 开放问题，不喊「谢谢大家我的分享到此结束」。

## 二、演示幻灯片分镜（slides）

`writing-craft` 只输出**逐页叙事分镜**（页标题 / 屏幕视觉锚点 / speaker notes 讲稿），不负责手工摆图；若本地有 ppt 类技能可交其渲染成 `.pptx`，缺失时直接交付完整逐页分镜与讲稿。

### 典型分镜流（按需增减页数）

| 页序 | 单页主论点 | 屏幕上放什么 | Speaker Notes 口播 |
|---|---|---|---|
| **P1 · 封面** | 直入话题的标题 | 标题 + 一句话主线 | 开场第一句钩子与今日收益 |
| **P2 · 速览 / 成果** | 为什么值得听（2–4 条短锚点或先亮结果） | 极简对比数字 / 核心变化卡片 | 先抛成果与背景张力，不做寒暄 |
| **P3–P4 · 痛点与转折** | 真正卡在哪里 | 一张截图 / 反例原话 / 对比表 | 具体讲当时为什么靠老办法行不通 |
| **P5–P8 · 解法与机理** | 一页只讲一件事 | 架构/流程图（借 `diagram_kit render`）或直观图（借 `content-infographic`） | 工程事实讲准，再决定要不要叠类比 |
| **P9 · 误区与选型** | 最容易想错的点 / 方案对比 | 三列表（方式 / 行不行 / 原因，✅/❌/⚠️ 标状态） | 点出适用边界，不硬吹方案 |
| **P10 · 真实边界** | 什么还做不到、留下了什么 | 半自动边界 vs 已沉淀资产对照 | 诚实交底，赢得同行信任 |
| **P11 · 收口** | 明天能带走的行动或 2–3 条平实体会 | 大字收口句 / 行动清单 | 总结收束 + 抛 Q&A 问题 |

### 幻灯片版面铁律

- **屏幕只放锚点，细节全进演讲者备注（notes）**：每页最多 `1` 个中心判断句 + `1` 个支撑物（图表、核心数字或 `3` 条以内的极短关键词），绝不把大段文字搬上投影。
- **图即证据**：精确架构图与流程图优先调用 `engineering-docs` 的 `diagram_kit render`，概念直观记忆图优先调用 `content-infographic`，图旁附一句导读。

## 三、三态轻量互转

| 转换方向 | 重点加减动作 |
|---|---|
| **文章 `article` → 口播 `talk`** | **砍**：复杂公式、大段引文、多列表格（改成口头对比）；**加**：开场时长与带走收益预告、节间显式过渡问句、关键数字的大白话翻译 |
| **文章 / 口播 → 分镜 `slides`** | **拆**：一节核心判断拆成 1–2 页 slide；**剥**：只把 1 句论点与 1 个图/数留屏幕，所有因果展开、踩坑故事与过渡话术全挪进 speaker notes |
| **分镜 `slides` → 文章 `article`** | **补**：把每页 notes 的口语展开补实工程机理、可查出处与真实边界；用自然小标题与短段落替换逐页翻页提示 |
