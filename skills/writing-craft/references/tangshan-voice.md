## 一、冷暖双声道与辩证退步写法

### 1.1 「冷酷现实主义 × 克制底层悲悯」双声道
汤山体区别于油腻「社会达尔文主义喷子」的根本分水岭，在于它同时握有两只手：
- **解剖结构时冷硬如铁**：不迷信口号、光环和道德声明，直白点透利益底线（「政客底线从来是由资产负债表的疼痛极限来标价的」「只要人设足够差，就永远不会塌方」）。
- **面对普通人与劳动者具体苦难时立刻收起戏谑**：绝不对真实苦难抖机灵，改用极克制的平实白描，零煽情形容词却让人心里发沉——比如算清几百块养老金买不起一件羽绒服，老人改低年龄去工地搬砖，只因「蔬菜可以自己种，但十块钱一斤的肉、二十块钱一盒的降压药，总得用真金白银去买」；或者算清大厂齿轮尽头是一个普通人能不能早点回家吃顿热饭的尊严。**「冷而不毒、凉中有温」**是这篇文风最高级别的格调压舱石。
- **C5 克制界线与议题适配**：C5 只用冰冷具体的生活实数与日常白描，严避「凌晨三点」「熬不完的红血丝」「工程敬畏」「透支用户信任」等自媒体煽情道具与道德说教尾巴；纯工程架构、组织管理或商业博弈议题优先用 **C1 冷句铁律**或 **C2 黑色反讽**干净落锤，不硬挤温情结尾。

### 1.2 标志性「辩证退步」转折动作
先承认具体个人和决策者的现实难处，**主动撤掉「坏人太蠢/太贪」的廉价靶子**，把读者拉回同一个博弈格子里，反而让结构之刀更加无从反驳。常见起手式：
- 「话又说回来，这事真不怪一线的安全员 / 一线的组长。」
- 「并不是说管理层天生又蠢又坏，相反，把你按在他的椅子上，面对同赛道三家都在靠裁员和外包把报表拉平，你不跟着压成本，下个季度投资人先用脚投票。」
- 「辩证地看，这何尝不是一次挤干泡沫、迫不得已的出清。」
- 「先声明，我绝不是看空人工智能技术本身，恰恰相反……」

## 二、冷幽默、公文戏仿与骨感混排

### 2.1 一本正经捧杀与体制/公文语体戏仿
最高级的讽刺从不提高音量咆哮，而是**顺着荒谬的逻辑极其严肃地捧到天上去**，或用纪检/官宣/通报体复述科技圈与商业界的草台内斗：
- **体制戏仿示范感**：讲硅谷 AI 巨头董事会闪电罢免创始人的荒唐政变，不用八卦口水，而是端出一副庄严的通报口吻：「经审查，该同志丧失了最初理想信念，对董事会不忠诚不老实，经研究决定，免去一切职务」——反差一笑，宫斗草台味自己就透出来了。
- **一本正经捧杀**：看到贫困区建起奢华却无人问津的度假设施时，顺嘴赞一句：「确实啊，乡亲们下地干完十小时农活，谁不想晚上换上装备去健身房再练组力量呢？」——零脏字，痛感拉满。

### 2.2 两套题材语域分流（严防语体撕裂）

| 题材类型 | 推荐语体与词汇边界 | 反面教训（避坑） |
|---|---|---|
| **硬核科技 / 工程 / 数学推演** | 冷静、精确、克制，写给一线同行或理性跨界读者看，靠因果洞察和机制准确立住信用，不硬拗江湖口吻；篇幅长或概念密时用简短凝练的 H2 路标（`4–10` 字）帮读者定位，节内用错落长短散文段落讲透，不把小标题写成长结论句，全篇仅在确有 `1–2` 处并列硬事实比段落省力时克制用短列表。 | 在类型系统、共识协议、统计口径等硬核机制旁边硬塞「吃干抹净」「吃哑巴亏」「露出馅」「卷得飞起」，在说书腔与工程文之间剧烈撕裂。 |
| **社会 / 商业 / 职场泛议论长评** | 顺着日常生活与组织博弈的烟火气，自然使用带物理痛感的口语词（如 `擦屁股`、`糊过去`、`按回地上`、`拉手刹`、`顶雷`），贴题而不喧宾夺主。 | 一味追求爽感堆砌粗俗梗，或把严肃制度痛点写成油滑段子合集。 |

### 2.3 防混合隐喻撞车
一个比喻没想透，绝不在同一句话里强拼两三个不搭界的意象。**撞车反例**：`在高速运转的齿轮里给地基打补丁、一票否决这场风暴`（齿轮打补丁 + 地基 + 一票否决 + 风暴多重冲突）、`拿一张漏风的体检表掌舵……船身顺着水温滑出了航道`（体检表 + 掌舵 + 水温 + 航道意象打架）。发现意象打架时，直接撤掉修辞、回到平实精准的机制直述。

## 三、句群咬合、书面提纯语法与笔记改造流

### 3.1 四拍句群咬合与「长铺短锤」真节奏
统计证实，汤山体书面文章平均句长在 `50–60` 字之间，极短句不到 `4%`——它靠的不是像机关枪一样连发短句或对仗，而是**长链密实算账后的突然截停**：
- **四拍推进节奏**：① 抛荒诞现象或一句切问 → ② 先退半步体谅各方理性 → ③ 中长句密密实实把数字、规则与因果链推实 → ④ 紧接一句 `≤15` 字的冷断句或对称短锤急刹（如 `修路的人破产了，卖车的人发财了。` / `累，成为常态；穷，成为结果。`）。
- **高杠杆表达手段（自然长在推导中，不按配额硬凑）**：
  - **抽象落成实物**：把「轻资产 / 核心能力」落回「一台电脑、一把椅子、一个推门走掉的人」。
  - **因果顶真推链**：把「由于 A、B、C 导致 D」拆成「因为 A，所以 B。因为 B，所以 C……」推着读者无法中途反驳。
  - **硬数字直接对撞**：用两个可验证的悬殊真数并排，不用「极大地」「非常」虚夸。
  - **克制镜像翻面**：同一组主客词前后对调，只用于整篇最重的一两处枢纽或收尾（例：`标准化时代人把自己练成机器；AI 时代机器成了机器，人重做回人`）。

### 3.2 口播或零散思考 → 书面精修三栏提纯法
把零散想法、内部笔记或语音转写稿锻造成书面长评时，按「砍 / 保 / 重构」三栏过一遍：

| 动作 | 具体操作 |
|---|---|
| **① 砍什么**（清零口语杂质） | 删净句尾气口词（啊/呢/嘛/这个/给）；切除广播自指（「我今天给大家聊聊」）与交互问候套话；去掉过于情绪化的即兴挑衅词与过满副词；把「今年夏天/某个月」去时效化成可持续阅读指称。 |
| **② 保什么**（留住人味而不硬凑） | 社会/商业评论留住贴题的市井实感动词；硬核科技/工程长文保持冷静克制、不硬塞说书腔；保留「辩证退步」缓冲句与把人拉回核心现场的对话锚点。 |
| **③ 重构什么**（版式随题材自适应） | **标题**：冒号两段式或直给反差单句标题均可，不用 `——`、`！` 或「……的隐形账单 / 背后的真相」式空心副题。<br>**结构分节**：硬核科技、工程或数学长文（如超 1,500 字）用简短凝练的 H2 路标（`4–10` 字）与错落长短散文段落为主，不把小标题写成长结论句，全篇列表克制在 `0–2` 处（只用于确属并列硬事实之处，不每节套用要点清单）；社会/商业叙事长评可按篇幅少用或不用 H2，靠话题枢纽句与短段节奏推进——既不写一坨文字墙，也不写成 PPT 汇报提纲。<br>**句段节奏与零乱加粗**：长密论证段与 `1–2` 句短转折段错落交错，正文默认纯白不加粗，不用自造加粗术语（如「**制度断层带**」）或重复句式充深刻；括号仅在必要处补全关键简称，数字用阿拉伯数字。 |

### 3.3 内部笔记 4 步改造流
1. **定靶点与骨架**：先判断现有笔记属于当下解剖还是未来推演，选定 1–2 条元公理与 7 类骨架中最合身的一套（短推演就顺畅短段直下，不必硬拉历史长卷）。
2. **补引擎与冷开**：补上能一秒穿透的那台「生活建模 / 话术翻译 / 反常数字账」，把流水账开头削成前三句亮刃的冷开。
3. **过语态与保真**：贴题时可用「辩证退步」防说教感；硬技术、历史年代与数据引证按 `references/tangshan-fidelity.md` 保真核查，再按题材选用冷静分节或自然短段节奏，并检查混合隐喻与降维红线。
4. **陈述句冷收 + 交洗**：把最后一个字钉在 C1/C2/C3/C5 陈述句上，交付前过一遍 `haohao-shuohua` 标准档清去残留 AI 腔。

## 四、跨题材通用武器库与财经赛道隔离区

### 4.1 可跨行业通用的高频逻辑枢纽词
- **转折劈开类**：`但是`、`其实`、`实际上`、`然而`、`不过`、`反而`、`相反`、`恰恰`、`讽刺的是`
- **降维翻译与压缩类**：`也就是说`、`本质上`、`换句话说`、`说白了`、`很简单`、`一句话`、`说到底`
- **递进与拉回注意类**：`注意`、`更重要的是`、`你看`、`记住`、`这还没完`、`往根儿上刨`、`退一万步讲`

### 4.2 可跨行业通用的物理痛感动词
- **结构拆解与博弈动词**：`倒逼`、`绑架`、`撕裂`、`反噬`、`阉割`、`窒息`、`裹挟`、`甩锅`、`塌方`、`摁住`、`设卡`、`吸干`、`掏空`
- **市井骨感动作词**：`掀桌子`、`焊死`、`捅穿`、`拉手刹`、`擦屁股`、`按回地上`、`贴价签`、`借尸还魂`

### 4.3 五大跨界通用隐喻域（优先选贴合当前机制的那一个域）
1. **物理 / 工程 / 基建**：地基、齿轮、刹车、承重墙、热气球与钢针、创可贴堵三峡、失灵定位的远洋船。
2. **游戏 / 赌桌 / 博弈**：牌桌、筹码、庄家、洗碗与吃饭（只让普通人洗碗、上桌没份）、左脚踩右脚上天。
3. **农业 / 庄园生态**：庄稼与土壤（整片枯萎看土壤）、树根与烂叶、蒙眼拉磨的驴、森林大火、草台班子。
4. **医学 / 病理**：大动脉流血不停打肾上腺素却不止血、医生踩到了病人的氧气管子、吃不饱被当成便秘开塞露、症状压成血栓。
5. **战争 / 军备竞赛**：拼刺刀、养寇自重、隔离带、降维打击（仅用于精准实力代数差，不空泛乱贴）。

### 4.4 财经赛道限定词隔离区（写非财经题材请绕行）
以下词语属于股票/货币/地产评述的特定行业黑话：**`收割`、`兜底`、`暴雷`、`接盘`、`韭菜`、`印钞机`、`剪刀差`、`夜壶`、`M2`、`社融`、`YCC`、`货币乘数`、`明斯基时刻`**。
- **正确用法**：抽走它们背后的**博弈逻辑**（例如「让后入局者为前任风险买单」「用短期补丁拖延结构出清」），换成当前领域里的真实机制词，**不要写篇软件工程、组织管理或 AI 评论还一口一个「被收割韭菜」「成了夜壶」**。

## 五、6 类噪音与反模式清零清单

从真实长时段口播语料中剔除以下 6 类历史杂质与翻车倾向，决不写进成稿：

1. **口播垫词与主持签出套话**：`啊/呢/对不对/朋友们大家好/好了关于今天的话题就聊这么多/点赞转发/下期再见`（书面稿必须完全消失）。
2. **套路化模块复读**：把同一两个历史桥段或顺口溜（如机械重复某几段「分税制」模板或万能金句梗）生硬往每篇里复制粘贴，沦为自我复读机。
3. **平台合规「安全垫」套话**：批判完一通结构问题，末尾突兀拐回一句「但值得欣喜的是在某某坚强指引下未来必定一片光明」式的应付式表态。
4. **早期硬广、卖书流与成功学导师腔**：避免「提升认知边界就能实现财富自由」「加入什么圈子把握时代密码」之类居高临下割焦虑的说教口吻。
5. **战狼爽文滑坡、粗俗生理梗与空洞排比**：拒绝贴脸骂人、下三路低俗比喻、轻信二手阴谋论，以及毫无实事支撑的「五千年文明屹立世界牌桌」式大词连排。
6. **为图顺口牺牲技术/史实精度**：这是最容易翻车的暗坑——宁可多写两句平实陈述交代边界与出处，也不为了憋出一句炸场比喻把原理讲错、年代写串或数量级搞错（详例见 `references/tangshan-fidelity.md`）。
